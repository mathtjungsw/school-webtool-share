# 2022 교과목 안내 적용 근거

사용자 제공 HWP 원본을 `python-hwpx 6.6.0`의 `HwpxDocument.open`으로 읽고 임시 HWPX 사본에서 스킬 TextExtractor로 본문·표를 추출했다. 원본은 보존했다. 변환 보고는 unconverted 0, dropped label-item 4였으며 과목명이 아닌 목록 레이블에 해당한다. 원본 과목·교과 목록과 추출 결과를 확인해 정적 사전을 작성했다. 문서를 재편집하거나 한컴 표시 품질을 검증한 작업은 아니다.

보통 교과와 과학·체육·예술·외국어/국제 계열 과목을 포함한다. 일반/진로/융합의 구분은 등급 가중평균 교과 선택과 무관하므로 사전은 교과군만 보관한다. 예: 한국사1·2→사회, 과학탐구실험1·2→과학, 정보과학→기술·가정/정보, 음악과 문화→예술. 부호 `*`는 과목명에서 제외한다. 기술·가정/정보와 제2외국어/한문은 안내의 묶음 분류를 사용한다.

자료에 없는 2015 교육과정 과목은 원본의 교과를 유지한다. 교과 정보도 없으면 국영수과사 계산에서 확인 필요로 처리한다. 과목 목록 자체만 앱에 포함하며 학생 정보·성적·첨부 원문은 공개 저장소/설치본에 포함하지 않는다.
