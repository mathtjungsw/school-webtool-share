# 웅천고 업무도우미 PC·모바일 기능 점검

2026년 11월 18일 · 학교 내부 검토용

**가장 먼저 할 일은 공개 배포물에서 개인별 수업 편성 자료를 분리하는 것이다.** 공개 저장소와 PC 패키지에서 학생 이름 6개가 학년·반·개별 수업 편성에 연결되는 것을 확인했다. 교사 당김수업 346건도 공개 소스에 들어 있다. 학교 개인정보 담당자가 실제 자료 여부와 공개 이력을 확인하고, 개발 담당자가 인증 후 필요한 수업만 전달하는 방식으로 바꾸기를 권한다. 외부인의 열람 여부는 이번 점검으로 알 수 없다.

| --- | --- |

실제 교직원 계정 로그인, 운영 학생 자료 조회, 모든 메뉴의 현장 수작업, 교내망 혼잡 시간대 속도, 사용 빈도, 클라우드 사용량은 검증 범위 밖이다. 모바일 로그인 이후의 동작은 저장소 코드와 합성 데이터 테스트 기준이다. 공개 모바일 화면과 로컬 빌드의 전체 일치 여부도 별도 확인이 필요하다.

| 보통 · PC 시작과 성적 입력 | 본창과 위젯이 같은 진입 파일에서 두 화면을 정적으로 불러온다. 재빌드한 주 진입 JS는 약 2.19 MB다. 시작 HTML은 외부 글꼴에도 접속한다. 추정분할점수는 상태가 바뀔 때 과목 전체를 직렬화해 동기 저장한다. | 본창·위젯 시작 코드를 나누고 Windows 기본 한글 글꼴 또는 동봉 글꼴을 사용한다. 성적은 변경분을 짧게 묶어 저장하되 과목 전환·종료 전에 마지막 변경을 보존한다. 200명 이상의 합성 성적으로 연속 입력 후 재실행 복원을 검증한다. |

30초 확인은 PC 정식 **업데이트 확인 주기와 별개**다. 업데이트는 시작 시와 마지막 확인 후 약 6시간 간격이다. 학교 데이터는 변경분을 공유하고, 실제 수업 직전의 예외·대강은 제때 보여 주는 것이 우선이다. 서버 비용과 절감률은 운영 사용량을 확인한 후 산정할 수 있다. [Google Apps Script 성능 지침](https://developers.google.com/apps-script/guides/support/best-practices)

## 3. 추가할 기능

1. **이 기기의 개인정보 관리.** 설정의 기존 ‘로컬 저장자료 모두 삭제’는 공유자료 캐시를 지운다. 이를 ‘공유자료 캐시 삭제’로 명확히 하고, 성적 초안·평균내신 자료·우수사례 파일을 별도 항목으로 보여 준다. 저장 위치, 사용자 범위, 마지막 저장일, 항목별 삭제를 제공한다. 사용자 작성 초안은 캐시 정리로 사라지지 않게 한다. 학생 이름 목록을 관리 화면에 다시 표시할 필요는 없다.
2. **공용 기기 모드.** 로그인할 때 ‘이 기기에 로그인 유지’를 선택하게 한다. 공용 기기에서는 세션과 개인 자료를 일시 보관하고, 기존 120시간 PC·72시간 모바일 유지 옵션은 개인 기기에 제공한다. 공용 PC에서 서로 다른 두 교사가 같은 Windows 계정을 사용할 때 이전 교사의 성적 초안이 열리지 않는지 검증한다.
3. **연결 문제 다시 확인.** PC는 세션 복원 요청이 실패하면 저장 세션도 지우는 경로가 있다. 서버가 만료를 확인한 경우와 교내망이 잠시 끊긴 경우를 구분하고 ‘연결 다시 확인’을 제공한다. 재확인 전에는 민감 화면을 잠근다. 모바일의 기존 ‘자료 상태’에는 마지막 정상 확인 시각과 실패한 자료만 다시 확인하는 동작을 연결한다.

**유지할 보호 장치.** 모바일 출결은 일정 화면에 요약을 제공하고, 사용자가 특정 교시를 선택할 때 서버가 로그인 교사의 수강생을 확인해 상세 명렬을 제공한다. 명렬은 팝업을 닫으면 화면 메모리에서 해제하며 서비스 워커는 인증 POST를 캐시하지 않는다. 평균내신의 격리·암호화·로컬 비우기, 교장·교감 메뉴의 추가 인증, 외부 웹앱의 분리된 화면도 유지할 가치가 있다. 저장소에 있는 Firestore 규칙은 직접 클라이언트 읽기·쓰기를 차단한다. 실제 프로젝트의 콘솔 권한과 운영 규칙은 이번에 대조하지 않았다.

## 권장 적용 순서

1. **공개 자료 대응.** 담당자와 노출 범위·기존 배포 상태를 확인하고 보호 조치를 결정한다. 새 PC·모바일 산출물과 공개 소스에 운영 명렬이 포함되지 않는지 검사한다. 인증한 교사는 자신의 수업을 정상적으로 볼 수 있어야 한다.
2. **시험판에서 보호와 속도 개선.** 성적 저장 전환, 사용자별 격리, 로그인 복원, 학생 자료의 필요 시 조회부터 적용한다. 합성 자료로 기존 초안 복원, 두 사용자 간 분리, 망 단절 후 복귀, 당김·교체·휴강·3학년 출결을 검증한다.
3. **교무실과 교실에서 비교.** 같은 PC·휴대전화로 기존판과 시험판을 새 실행·재실행 각각 여러 번 측정한다. 로그인 후 오늘 시간표가 보일 때까지의 시간, 10분 유휴 시 호출 수, 시간표 변경이 두 기기에 보일 때까지의 시간, 출결 버튼 응답을 비교한다. 이름·학번·조회 내용 없이 수치만 수집한다. 알림과 주간 메뉴는 담당자가 기존 업무를 끝까지 수행할 수 있는지 확인한 뒤 통합한다.
