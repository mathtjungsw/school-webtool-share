# 누적 개선 계획

이 문서는 사용자가 전달한 개선 의견을 시험판 제작 전까지 보관하는 대기 목록입니다.

## 작업 규칙

- 개선 의견 단계에서는 이 문서만 갱신하고 코드·버전·설치파일·배포 상태는 변경하지 않는다.
- 사용자가 시험판 제작을 요청하면 아래 대기 항목 전체를 시험판에 구현하고 검증한다.
- 시험판 제작과 검증이 끝나면 아래 대기 목록을 비운다.
- 사용자가 업데이트 배포를 요청하면 정식 버전 개발과 자동 업데이트 배포 절차를 진행한다.
- 긴급 업데이트가 필요해 보이면 사용자에게 먼저 확인받는다.

## 대기 중인 개선안

### 2026-09-14 교장·교감 전용 메뉴

#### 목표와 메뉴 구조

- 로그인 계정이 `류희열`이면 `교장메뉴`, `이승훈`이면 `교감메뉴` 묶음을 대시보드 바로 아래에 표시한다.
- 일반 교직원에게는 묶음과 하위 메뉴를 모두 표시하지 않는다.
- 처음에는 두 역할에 공통으로 `현재 수업 현황`, `교사 시간표`를 제공하고, 이후 하위 메뉴를 추가할 수 있는 확장형 구조로 만든다.
- 조회 전용 화면으로 구성해 실수로 원본 시간표나 수업 변경 자료를 수정할 수 없게 한다.

#### 추가 인증과 권한 보호

- 지정된 두 계정은 이름 로그인 직후 역할별 추가 비밀번호 창을 한 번 더 거쳐야 한다.
- 사용자가 지정한 초기 비밀번호는 소스·문서·로그에 평문으로 저장하지 않고, 배포 시 서버 설정에 안전한 해시 형태로 등록한다.
- 본인은 현재 비밀번호를 확인한 뒤 새 비밀번호로 변경할 수 있고, 초기화는 관리자 모드에서만 할 수 있게 한다.
- 메뉴를 화면에서 숨기는 것에 그치지 않고 `현재 수업 현황`과 전체 교사 시간표 조회 요청도 서버에서 역할과 인증 세션을 다시 검사한다.
- 로그인 실패 횟수 제한과 짧은 재시도 대기 시간을 적용하고, 실패 메시지로 등록 계정 여부를 추정할 수 없게 한다.
- 비밀번호 변경·관리자 초기화는 값 자체를 남기지 않고 처리 시각·처리 유형·처리 주체만 감사 이력에 기록한다.
- 앱 종료 또는 인증 유효시간 만료 후에는 추가 인증을 다시 요구하고, 보호 화면 전체 자료는 장기 로컬 캐시에 남기지 않는다.

#### 현재 수업 현황

- 화면 상단에 `실제 교사 사용 여부에 따라 나이스와 차이가 있을 수 있습니다` 경고를 항상 표시한다.
- 현재 시각과 학교 일과시간을 대조해 현재 교시를 자동 선택하고, 쉬는 시간·점심시간·수업 전후에는 그 상태와 다음 교시를 분명히 표시한다.
- 상단 요약에는 현재 교시, 수업 중 교실 수, 공실 수, 확인 필요 건수를 표시한다.
- 학년·특별실 필터와 교실·교사·과목 검색을 제공한다.
- 교실 카드는 `교실`, `학년·반 또는 이동수업`, `과목`, `담당 교사`, `상태`를 한눈에 보여준다.
- 상태는 정상·교환·대강·당김수업·일일시간표 예외·확인 필요·수업 없음으로 구분하고, 밝은 모드에서 서로 쉽게 구별되는 배지와 테두리를 사용한다.
- 승인·반영된 수업 교환·대강·당김수업과 공유 `일일시간표예외`를 기본 주간시간표 위에 우선 적용한다.
- 이동수업은 실제 배정 교실을 기준으로 표시하고, 같은 교실의 중복 수업·같은 교사의 동시간대 중복·교실 또는 교사 누락은 `확인 필요`로 분류한다.
- 마지막 자료 갱신 시각과 새로고침 버튼을 제공하며, 일부 출처 조회 실패 시 전체 화면을 비우지 않고 이전 자료와 출처별 오류 상태를 함께 보여준다.
- 승인된 예상 화면처럼 교실을 학년·층·특별실 단위의 간결한 카드 격자로 배치한다.

#### 교사 시간표

- 전체 교사 명렬을 가나다순으로 표시하고 이름·교과 검색을 제공한다.
- 교사를 누르면 해당 교사의 주간시간표와 선택 날짜의 실제 시간표를 표시한다.
- 실제 시간표에는 승인·반영된 교환·대강·당김수업과 일일시간표 예외를 반영하고, 기본 시간표와 달라진 칸은 사유별 색상과 설명으로 구분한다.
- 다른 교사의 시간표를 확인하는 동안에도 원본 자료를 수정할 수 없는 조회 전용 화면으로 유지한다.

#### 개인정보와 예외 처리

- 첫 버전의 현재 수업 현황에는 학생 이름·학번·출결 등 학생 개인정보를 포함하지 않는다.
- 교실이나 교사가 확정되지 않은 수업은 임의로 추정하지 않고 `미지정` 또는 `확인 필요`로 표시한다.
- 서버 연결이 끊기거나 추가 인증이 만료된 경우 일반 화면으로 안전하게 돌아가고 보호 자료를 계속 노출하지 않는다.

#### 구현·검증 완료 기준

- 두 지정 계정의 메뉴명·위치·추가 인증, 일반 계정의 메뉴 미노출, 잘못된 비밀번호 차단을 검증한다.
- 본인 비밀번호 변경과 관리자 전용 초기화, 만료 세션의 재인증, 서버 액션 직접 호출 차단을 검증한다.
- 교시 경계·쉬는 시간·점심시간·수업 전후와 교환·대강·당김·일일 예외 우선순위를 각각 테스트한다.
- 교실·교사 중복 및 누락 경고, 출처 일부 실패 시 이전 자료 유지, 갱신 시각 표시를 테스트한다.
- 밝은 모드와 100%·125%·150%·200% 배율에서 글자 대비, 카드 잘림, 가로 스크롤을 점검한다.
- 이 항목은 현재 개선계획만 확정한 상태이며, 사용자가 시험판 제작 또는 업데이트 배포를 명시적으로 요청하기 전에는 코드·버전·설치파일·배포 상태를 변경하지 않는다.
