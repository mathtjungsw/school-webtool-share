# 누적 개선 계획

이 문서는 사용자가 전달한 개선 의견을 시험판 제작 전까지 보관하는 대기 목록입니다.

## 작업 규칙

- 개선 의견 단계에서는 이 문서만 갱신하고 코드·버전·설치파일·배포 상태는 변경하지 않는다.
- 사용자가 시험판 제작을 요청하면 아래 대기 항목 전체를 시험판에 구현하고 검증한다.
- 사용자가 업데이트 배포를 요청하면 정식 버전 개발과 자동 업데이트 배포 절차를 진행한다.
- 구현·검증·배포가 끝난 항목은 대기 목록에서 지우고 해당 릴리스 검증 문서에 기록한다.

## 대기 중인 개선안

### 2026-09-25 사용성 점검 반영 — 구현·로컬 검증 완료, 배포 대기

- 사용자 승인: 추천 1·3·4·5·6·7·8·9·10 반영. **2번 모바일 출결 팝업 갱신 방식은 제외**.
- 모바일: 안내 접기·행 높이 축소로 더 많은 교시 표시, 출처별 자료 상태와 날짜를 포함한 확인 시각, 지난주·이번 주·다음 주 시간표 이동, 긴 일정 상세 보기.
- PC: 한국 날짜 기준 통일, 교사 시간표·대시보드·학생 위치 찾기의 출처별 수신 상태, 위젯 업무·알림 원본 바로가기, 개인 업무 수정, 여러 교시 예외의 변경 전후 미리보기와 범위 충돌 안내, 인쇄 축소 후 재검사·여러 장 출력.
- 보안·로그인·모바일 출결 갱신·공유 서버 계약은 변경하지 않음.
- 상세 구현·검증 및 범위: [사용성 개선 검증 기록](REVIEW_USABILITY_2026_09_25.md).
