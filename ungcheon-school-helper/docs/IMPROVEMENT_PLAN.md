# 누적 개선 계획

이 문서는 사용자가 전달한 개선 의견을 시험판 제작 전까지 보관하는 대기 목록입니다.

## 작업 규칙

- 개선 의견 단계에서는 이 문서만 갱신하고 코드·버전·설치파일·배포 상태는 변경하지 않는다.
- 사용자가 시험판 제작을 요청하면 아래 대기 항목 전체를 시험판에 구현하고 검증한다.
- 시험판 제작과 검증이 끝나면 아래 대기 목록을 비운다.
- 사용자가 업데이트 배포를 요청하면 정식 버전 개발과 자동 업데이트 배포 절차를 진행한다.
- 긴급 업데이트가 필요해 보이면 사용자에게 먼저 확인받는다.

## 대기 중인 개선안

### 업무·일정 기간·시간 통합 및 교시 지정 입력

- 2026-09-08 검토 시안의 밝은 모드 구성을 최종 UI 방향으로 사용한다.
- 현재의 `시작일`, `마감일`, `실제 진행 시간(선택)` 구조를 없애고 시작·마감 입력 영역으로 통합한다.
- 시작과 마감은 각각 `날짜 + 선택형 시간`으로 구성한다. 두 시간 모두 비워두면 해당 기간의 종일 업무로 처리한다.
- 시작 시각만 입력하면 시작일의 해당 시각에 발생하는 시점 업무로 표시하고, 시작·마감 시각을 모두 입력하면 두 날짜·시각 사이의 기간 업무로 표시한다.
- 같은 날짜에서 마감 시각이 시작 시각보다 빠른 값은 저장하지 못하게 안내한다. 여러 날짜에 걸친 업무는 시작일시와 마감일시를 그대로 보존한다.
- 업무와 일정을 등록할 때 `시간으로 입력`과 `교시로 입력` 중 하나를 선택할 수 있게 한다.
- 입력 방식은 업무 기간 제목 옆의 간결한 분할 버튼으로 전환하고, 시작·마감의 날짜와 시간 또는 교시를 각각 같은 줄에 배치한다. 작은 화면에서는 시작과 마감을 위아래로 재배치한다.
- 교시 입력은 `2교시`처럼 한 교시만 지정하거나 `2~4교시`처럼 시작·종료 교시를 지정할 수 있게 한다.
- 단일 교시는 해당 교시 시작~종료 시각으로, 교시 범위는 시작 교시의 시작 시각~종료 교시의 종료 시각으로 해석한다.
- 점심시간을 사이에 둔 범위는 점심시간 전체를 하나의 업무 시간으로 칠하지 않고, 해당 교시 행들에만 같은 업무를 이어서 표시한다.
- 시간 직접 입력 기능은 그대로 유지한다. 사용자가 교시를 선택하면 학교 일과시간 설정을 기준으로 실제 시각을 자동 계산해 시간표·위젯·캘린더에 동일하게 표시한다.
- 일과시간을 나중에 수정해도 교시로 등록한 항목은 새 교시 시각을 따르도록 입력 방식과 시작·종료 교시를 함께 저장한다. 직접 입력한 시각은 자동 변경하지 않는다.
- 업무 목록과 상세 화면에는 `2교시`, `2~4교시` 표기를 우선 보여주고, 필요한 곳에는 계산된 실제 시각을 함께 표시한다.
- 입력 영역 아래에는 `2~4교시 · 09:40~12:30으로 표시됩니다.`처럼 계산 결과를 저장 전에 바로 확인하는 안내를 표시한다.
- 웹버전의 오늘 교사시간표에서도 업무·일정 필터를 제공하고, 켜진 자료를 함께 표시한다. 시간이나 교시가 지정된 업무는 해당 시간표 행의 오른쪽 일정 영역에 표시한다.
- 오늘 교사시간표는 왼쪽 `수업`, 오른쪽 `업무·일정`의 2열 구조로 구성하고, 여러 교시에 걸친 업무는 시작·진행 중·종료 상태를 각 교시 행에 자연스럽게 이어서 표시한다.
- 시간이 없는 종일 업무는 특정 교시 전체를 차지하게 하지 않고 오늘 시간표 상단의 간결한 `종일 업무` 영역에 표시한다. 필터를 끄면 시간 지정·종일 업무가 모두 숨겨진다.
- 기존 `scheduledDate`, `startTime`, `endTime` 자료는 새 시작·마감 일시 구조로 안전하게 읽고 이전한다. 기존 업무·일정과 서버 시트 자료가 사라지거나 중복 표시되지 않게 한다.

### 청렴 연수 등록부 기준 교직원 명렬 보강 및 정렬

- 기준 자료는 `2026. 학교로 찾아가는 청렴 연수 등록부.xlsx`의 2026-05-08 명단으로 하며, 등록부에서 확인한 총 66명을 교직원 명렬 반영 대상으로 사용한다.
- 등록부 44번의 `최대식`은 현재 교직원명에 맞춰 `전종택`으로 바꾼 뒤 저장·조회·로그인·시간표 연결 등 이름을 사용하는 모든 교직원 명렬 기능에서 동일인으로 처리한다. 기존 `전종택` 자료와 중복 행을 만들지 않는다.
- 교직원 명렬의 직책 우선순위는 등록부의 순번과 사용자가 지정한 순서를 따라 `교장 → 교감 → 행정실장 → 교사 → 행정과장 → 행정주임 → 시설관리 → 사무행정 → 교무행정 → 영양사 → 조리사 → 조리실무사 → 청소 → 당직`으로 고정한다.
- 같은 직책 안에서는 성명을 한국어 가나다순으로 정렬한다. 등록부의 개별 순번을 그대로 유지하는 것이 아니라 직책군의 순서를 정하는 근거로 사용한다.
- 교원뿐 아니라 아래 비교원 19명도 공유 교직원 명렬에 포함한다.
  - 행정실장: 김우열
  - 행정과장: 문은희
  - 행정주임: 박정희, 정지수
  - 시설관리: 이문원
  - 사무행정: 문소영
  - 교무행정: 오지윤
  - 영양사: 이선경
  - 조리사: 홍인숙
  - 조리실무사: 강해선, 고윤경, 김미령, 윤외희, 윤하영, 정현선, 조경염, 최혜진
  - 청소: 전영애
  - 당직: 이정우
- 조리실무사 명단은 원본 순번 57~64의 `조경염, 윤외희, 김미령, 강해선, 고윤경, 정현선, 윤하영, 최혜진` 8명으로 확정하며 가나다순 표시 결과는 `강해선, 고윤경, 김미령, 윤외희, 윤하영, 정현선, 조경염, 최혜진`으로 한다.
- 등록부에는 직책·성명만 있으므로 기존 교사의 부서·교과·담임 정보는 이름 기준으로 병합해 보존한다. 엑셀을 다시 불러와도 빈 열 때문에 기존 부서·교과·담임이 지워지지 않게 한다.
- 새로 추가되는 비교원의 부서·교과·담임은 임의로 만들지 않고 빈 값으로 시작하며, 필요한 경우 관리자 편집 화면에서 보완할 수 있게 한다.
- 엑셀 불러오기 직후 미리보기, 공유 명렬 저장 후 서버 정렬, 일반 조회, 명렬 내려받기, 연수등록부의 `전체 교직원` 범위에서 모두 같은 66명과 같은 정렬 순서를 사용한다.
- 회귀검사에는 직책 우선순위 전체, 동일 직책 가나다순, `최대식 → 전종택` 정규화, 기존 교사 정보 보존, 중복 이름 방지, 전체 인원 66명 및 연수등록부 출력 순서 일치를 포함한다.
