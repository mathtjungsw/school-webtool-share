# 누적 개선 계획

이 문서는 사용자가 전달한 개선 의견을 시험판 제작 전까지 보관하는 대기 목록입니다.

## 작업 규칙

- 개선 의견 단계에서는 이 문서만 갱신하고 코드·버전·설치파일·배포 상태는 변경하지 않는다.
- 사용자가 시험판 제작을 요청하면 아래 대기 항목 전체를 시험판에 구현하고 검증한다.
- 시험판 제작과 검증이 끝나면 아래 대기 목록을 비운다.
- 사용자가 업데이트 배포를 요청하면 정식 버전 개발과 자동 업데이트 배포 절차를 진행한다.
- 긴급 업데이트가 필요해 보이면 사용자에게 먼저 확인받는다.
