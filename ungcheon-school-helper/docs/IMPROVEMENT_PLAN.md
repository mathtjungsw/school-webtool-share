# 누적 개선 계획

이 문서는 사용자가 전달한 개선의견을 시험판 제작 전까지 보관하는 대기 목록이다.

## 작업 규칙

- 개선의견 단계에서는 이 문서만 갱신하고 앱 코드·버전·설치파일·배포 상태는 변경하지 않는다.
- 시험판 제작 요청이 들어오면 아래 항목 전체를 시험판에 구현하고 검증한다.
- 시험판 제작과 검증이 성공하면 아래 대기 목록을 비운다.
- 업데이트 배포 요청이 들어오면 정식 버전 개발과 자동 업데이트 배포 절차를 진행한다.
- 긴급 업데이트가 필요해 보이면 사용자에게 먼저 확인받는다.

## 대기 중인 개선안

### 대시보드 시간표

- 달력에서 선택한 날짜처럼 시간표에서도 해당 요일 열 전체가 한눈에 구분되도록 표시한다.
- 현재 수업·현재 시각 표시는 기존 방식대로 유지한다.
- 교사 시간표 아래의 학급 시간표에 `숨기기/보이기` 버튼을 추가한다.
- 담임이 아닌 사용자도 필요에 따라 학급 시간표 영역을 접어 둘 수 있게 한다.

### 각종위원회 화면 가독성

- 밝은 모드에서 상단 카드의 배경과 제목·설명·탭 글자가 겹쳐 보이지 않는 문제를 수정한다.
- 밝은 모드에서는 밝은 배경과 진하고 어두운 글자, 다크 모드에서는 어두운 배경과 밝고 선명한 글자를 사용한다.
- `학교 내 각종위원회` 제목, 기준 안내, 설명, `기준표·위원 명단`, `위원회 캘린더`, 공동 편집 안내와 우측 버튼까지 모두 점검한다.
- 같은 상단 카드 구조를 사용하는 다른 메뉴도 함께 확인해 동일한 대비 문제를 예방한다.
- 실제 밝은 모드와 다크 모드 화면을 각각 확인해 글자 가독성을 검증한다.
