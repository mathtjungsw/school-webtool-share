# 누적 개선 계획

이 문서는 사용자가 전달한 개선 의견을 시험판 제작 전까지 보관하는 대기 목록입니다.

## 작업 규칙

- 개선 의견 단계에서는 이 문서만 갱신하고 코드·버전·설치파일·배포 상태는 변경하지 않는다.
- 사용자가 시험판 제작을 요청하면 아래 대기 항목 전체를 시험판에 구현하고 검증한다.
- 사용자가 업데이트 배포를 요청하면 정식 버전 개발과 자동 업데이트 배포 절차를 진행한다.
- 구현·검증·배포가 끝난 항목은 대기 목록에서 지우고 해당 릴리스 검증 문서에 기록한다.

## 대기 중인 개선안

### 교장·교감 계정의 위젯 자동 로그인과 보호 메뉴 인증 분리

- 일반 사용자 세션과 교장·교감 보호 메뉴 세션을 서로 다른 권한 단계로 분리한다.
- 류희열·이승훈 계정도 일반 사용자와 동일하게 이름·72시간 기본 로그인 세션을 복원하여 위젯이 자동 로그인되게 한다.
- 위젯에는 기본 로그인 이름만 전달하고 교장·교감 보호 메뉴의 역할·접근 토큰·추가 비밀번호는 전달하거나 저장하지 않는다.
- 프로그램을 다시 실행했을 때 기본 로그인은 유지하되 `교장메뉴`·`교감메뉴`는 잠긴 상태로 시작한다.
- 보호 메뉴를 처음 열 때 추가 비밀번호를 다시 확인하고, 인증된 현재 프로그램 창에서만 제한 시간 동안 보호 메뉴를 사용하게 한다.
- 추가 인증이 만료되면 프로그램 전체를 로그아웃하지 않고 보호 메뉴만 닫고 다시 잠근다.
- 본 프로그램 로그인 직후 실행 중인 위젯에 인증 변경 알림을 보내고, 위젯은 저장된 기본 세션을 다시 읽어 같은 사용자 자료를 즉시 불러온다.
- 교장·교감 계정의 위젯 자동 로그인, 일반 교사 자동 로그인, 보호 메뉴 재인증, 만료·로그아웃 동기화를 각각 회귀검사한다.

### 모바일 PWA 3학년 수업 출결 전체 명렬·비고 필터

- 3학년 수업의 출결 버튼을 누르면 이동수업·학급수업·교체·대강·당김수업 모두 실제 수강생 전체 명렬을 표시한다.
- 출결 팝업 상단에 `전체 명렬`과 `비고만` 전환 버튼을 둔다. 기본값은 `전체 명렬`이며 `비고만`에는 비고가 입력된 인원수를 함께 표시한다.
- 전체 명렬에는 실제 수강생의 `반·번호 | 이름 | 출결 비고`를 표시하고 비고가 없는 학생은 빈칸 대신 `비고 없음`으로 명확하게 나타낸다.
- 정렬은 자습 여부나 비고 종류로 재배치하지 않고 원소속 반과 번호의 숫자 오름차순, 즉 학번 순서로 고정한다.
- `자습` 비고는 장소 이동임을 알아보기 위한 연두색 표시는 유지하되 별도 구역으로 모으거나 목록 아래로 이동하지 않는다.
- 전체 명렬은 기존 일정 묶음에 항상 포함하지 않는다. 로그인한 교사가 출결 버튼을 눌렀을 때만 별도 인증 API로 해당 날짜·교시의 담당 수업 명렬을 요청하여 다른 교사의 수업이나 학급 전체 자료가 노출되지 않게 한다.
- 서버는 로그인 세션의 이름과 요청 교사를 다시 대조하고 해당 수업의 반·번호·이름·비고만 반환한다. 학번 원본, 학생시간표 payload, 과목 선택 원본 및 다른 수업 자료는 반환하지 않는다.
- 상세 명렬은 서비스 워커와 장기 IndexedDB 캐시에 저장하지 않고 화면 메모리 및 5분 이내의 제한된 조회 캐시만 사용한다. 팝업을 닫거나 로그아웃하면 메모리 자료를 지운다.
- `비고만` 전환은 이미 받은 해당 수업 명렬을 화면에서 즉시 필터링하며 추가 서버 조회를 만들지 않는다.
- 전체 명렬 수, 비고 인원, 반별 입력 상태, 수강생 불일치 건수 및 변경수업 종류 표시는 기존 출결 요약과 일치하게 유지한다.
- 공동교사·축약 교사명, 복수 반 이동수업, 일반 학급수업, 교체·대강·당김수업, 자습 포함 목록, 비고 0명과 일부 입력 상태를 회귀검사한다.
