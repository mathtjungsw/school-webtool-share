# v1.1.31 일일 시간표 예외·업무 기간 통합 검증

기준일·최종 확인일: 2026-09-11
기준 소스: 작업 시작 시 최신 `origin/main` 데스크톱 v1.1.30 / 모바일 PWA v1.1.28 / 공유 서비스 44

## 구현 범위

- 공유 구글시트 `일일시간표예외`·`일일시간표예외이력`과 관리자용 일일 시간표 예외 관리 화면을 추가했다.
- 2026-09-11 7교시는 1·2학년의 2026-09-23 수요일 7교시를 복사하고, 3학년의 2026-09-23 7교시 당김수업을 이동한다.
- 2026-09-23은 기존 2~6교시를 1~5교시로 이동하고 6·7교시를 비운다.
- 예외는 교사 주간·월별 시간표, 대시보드, 위젯, 학생 위치 찾기, 학생 특정 시간 위치 찾기와 모바일 시간표에서 같은 공유 자료를 사용한다.
- 업무 시작·마감 영역에서 선택 시간 또는 시작·종료 교시를 입력하고, 입력하지 않으면 종일 업무로 처리한다. 기존 `scheduledDate` 자료는 하위 호환으로 읽는다.
- 청렴 연수 등록부 기준 비교원 19명을 보강하고 `교장 → 교감 → 행정실장 → 교사 → 나머지 직책군` 순서와 직책 내 가나다순을 적용한다. `최대식`은 `전종택`으로 정규화하며 기존 부서·교과·담임을 보존한다.
