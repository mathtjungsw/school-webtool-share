# v1.1.35 교장·교감 위젯 자동 로그인·보호 메뉴 인증 분리 검증

기준일: 2026-09-22
기준 소스: 최신 `origin/main` 기반 데스크톱 v1.1.35

## 구현 범위

- 류희열·이승훈 계정의 이름 로그인과 72시간 기본 세션 복원
- 로그인 직후 위젯 인증 변경 알림 및 기본 세션 재읽기
- 위젯에는 이름 기반 기본 세션만 제공하고 보호 메뉴 역할·토큰·비밀번호는 미전달
- `교장메뉴`·`교감메뉴`를 열 때 현재 프로그램 창에서만 추가 인증
- 보호 메뉴 인증 만료 시 전체 로그아웃 대신 보호 메뉴만 잠금
- 일반 교사의 기존 로그인·위젯 자동 연결 동작 유지

- [x] 보호 메뉴 인증 만료가 프로그램 전체 로그아웃으로 이어지지 않음
