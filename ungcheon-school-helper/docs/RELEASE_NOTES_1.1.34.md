# 웅천고 업무도우미 v1.1.34

- 바탕화면 위젯의 오늘 시간표에서도 3학년 실제 수강생 출결을 읽기 전용으로 확인할 수 있습니다.
- 승인·반영된 교체·대강·당김수업과 일일 시간표 예외를 반영해 출결 버튼이 실제 수업 교시에 표시됩니다.
- 모바일 PWA와 위젯에서 출결 비고에 `자습`만 적힌 학생은 실제 출결 이상과 분리해 연두색 `자습 · 장소 이동`으로 표시합니다.
- 출결 버튼은 실제 출결 인원과 자습 인원을 분리해 보여주며, 상세 화면에는 반·번호·이름·비고만 제공합니다.
- 위젯 출결은 5분 간격으로 갱신하고, 학교 공유 서버에는 최소 결과만 응답하도록 제한했습니다.
- 기존 Apps Script와 모바일 PWA의 고정 공개 주소, 모바일 72시간 로그인, 이전 릴리스 안내를 모두 유지합니다.
