# 5번 상세계획 · 업무알리미를 통합 알림·변경센터로 합치기

2026년 11월 18일 · PC판 · 상세계획 작성 완료 · 전체 항목 검토 후 통합 시험판 제작

## 1. 교사가 사용하는 화면

사이드바에서 ‘통합 알림·변경센터’를 열면 기존 업무·위원회·교환·대강 알림과 함께 ‘오늘 학사일정 알림’ 설정이 보인다. 이곳에 자동 확인 켜기·끄기, ‘지금 확인’, 오늘 일정, 마지막 정상 확인 시각을 둔다. 기존 통합센터의 읽음·내일 다시 보기 상태는 보존한다.

| 상황 | 동작 |
| --- | --- |
| 기존 업무알리미를 켜 둔 PC | 기존 설정 `notifier.sharedEnabled`를 이어받아 유효한 앱 로그인 후 자동 확인을 시작한다. 기존에 껐거나 처음 사용하는 PC는 끔 상태로 시작한다. |
| 다른 메뉴 사용·위젯만 실행·트레이에 숨김 | 자동 확인이 켜져 있으면 PC당 한 작업이 15분마다 학교 공용 자료에서 오늘 학사일정을 확인한다. 메뉴를 떠나거나 본창을 닫아도 트레이에서 앱이 실행 중이면 계속한다. |
| 자동 확인 끔 | 주기 확인과 학사일정 Windows 알림을 멈춘다. ‘지금 확인’은 오늘 일정과 확인 시각을 화면에 한 번 표시한다. 이 동작이 자동 확인을 다시 켜지는 않는다. |
| 로그아웃·세션 만료·완전 종료 | 확인을 멈추고 늦게 도착한 응답도 표시하지 않는다. 같은 날 다시 로그인하면 저장한 설정과 마지막 안내 상태를 이어간다. |
| 예전 메뉴로 진입 | ‘업무알리미’와 ‘업무 알리미’ 검색, 대시보드 바로가기, 기존 즐겨찾기에서 새 센터의 ‘오늘 학사일정 알림’으로 이동한다. |

## 2. 무엇을 언제 알릴지

- **첫 안내.** 한국 날짜 기준으로 자동 확인이 켜져 있고, 정상 확인한 오늘 일정이 있으면 하루 첫 안내 한 번을 보낸다. 일정이 없으면 센터에 ‘오늘 일정 없음’을 표시한다. 이후 새 일정이 생기면 그때 안내한다.
- **변경 안내.** 공용 자료의 일정에는 날짜·행사명·대상 구분이 있다. 이 값을 정규화하고 순서를 정리해 직전 정상 내용과 비교한다. 건수가 같아도 행사명이나 대상이 바뀌면 변경으로 인식한다. 여러 건이 한 번에 바뀌면 ‘오늘 학사일정이 변경되었습니다’로 한 번만 알리고, 센터에서 변경 전후를 확인한다. 순서·공백·조회 시각만 바뀌면 재알림하지 않는다. 취소는 정상 자료에서 기존 일정이 사라졌음을 확인했을 때만 반영한다.
- **중복 방지.** 날짜·앱 사용자별로 직전 안내 상태를 PC에 보관한다. 15분 확인, ‘지금 확인’, 두 창의 동시 실행, 같은 날 재시작이 겹쳐도 같은 내용으로 팝업을 다시 띄우지 않는다. 앱이 꺼져 있던 동안의 지난 날짜 알림은 쌓아서 보내지 않는다.
- **자료 지연.** 네트워크 실패, 조회 기간에 오늘이 없음, 관리자 동기화에서 학사일정 수집 실패는 ‘확인 필요’로 표시한다. 직전 정상 일정을 유지하고 전 일정 취소나 새 변경으로 판정하지 않는다. PC에서 확인한 시각과 관리자 자료가 갱신된 시각은 구분한다.
- **Windows 알림.** 알림을 클릭하면 통합센터의 오늘 일정으로 연결한다. Windows 알림이 차단되거나 방해 금지가 켜져 있어도 센터에서는 일정과 변경 내용을 볼 수 있게 한다. 운영체제가 팝업을 실제로 보여 줬다고 단정하는 상태 표시는 사용하지 않는다.

## 3. 구현과 기존 설정 이전

1. 현재 업무알리미 화면의 15분 타이머를 PC 앱의 로그인 수명에 맞춰 한 곳에서 관리한다. 시작·복귀·설정 켜기를 합치고 진행 중인 정기·수동 조회는 공유한다. 설정 끄기와 로그아웃 시에는 진행 중 요청의 늦은 결과도 알림으로 이어지지 않게 한다.
2. 관리자가 이미 동기화한 공용 NEIS 학사일정을 읽는다. [3번 계획](2026-11-18-desktop-widget-schedule-sync.md)의 공유자료 버전과 기존 캐시를 재사용해 변경이 없는 경우 전체 급식·시간표를 다시 받지 않는다. 개별 PC가 NEIS 원본을 다시 수집하지 않는다. 15분은 공용 자료를 확인하는 간격이며 원본 변경을 학교 서버가 수집하는 시점은 별개다.
3. 기존 통합센터에 설정과 결과를 추가하고 단독 업무알리미 메뉴와 페이지 타이머를 제거한다. 메뉴 등록부, 사이드바, 대시보드, 사용 안내와 업무 검색을 함께 수정한다. 예전 메뉴 식별자 `notifier`는 호환 경로로 처리하며 옛 메뉴와 통합센터를 모두 고정한 경우 한 번만 표시한다.
4. PC 시간표 동기화, 자동 업데이트, 기존 업무·위원회·수업변경 알림에는 각각의 확인 주기와 사용자 설정을 적용한다. 오래된 별도 모니터링 코드가 자동 실행되거나 중복 알림을 내지 않는지도 확인한다.

## 4. 시험판 합격 기준

| 시험 | 확인할 결과 |
| --- | --- |
| 설정·진입 경로 이전 | 기존 켬·끔·미설정 PC가 각각 켬·끔·끔으로 시작한다. 검색, 대시보드, 고정 메뉴는 새 센터로 연결되고 단독 메뉴는 남지 않는다. 기존 통합 알림의 읽음·다시 보기 상태가 유지된다. |
| 백그라운드에서 30분 | 다른 메뉴, 위젯 단독, 트레이 상태에서 최초 조회 후 가상 시계로 30분 동안 정기 확인이 각각 2회다. 두 창을 열어도 횟수가 늘지 않는다. 완전 종료·로그아웃 시 정기 확인은 0회다. |
| 중복·변경 감지 | 같은 날 같은 일정으로 수동 확인·재시작을 반복해도 첫 자동 안내는 1회다. 행사명 변경, 대상 변경, 추가, 정상 취소는 변경 묶음당 1회다. 순서 변경이나 공백 수정은 0회다. |
| 오류·복구·날짜 변경 | 동기화 실패를 전체 취소로 오인하지 않는다. 실패 후 같은 내용이 복원되면 중복 안내하지 않는다. 다음 날은 그날의 첫 정상 일정으로 새 안내를 시작한다. |
| 설정 끄기·알림 차단 | 자동 확인을 끄면 진행 중이던 응답도 Windows 알림을 띄우지 않는다. 수동 확인은 계속 가능하다. Windows 팝업이 차단된 환경에서도 센터에서 오늘 일정을 확인한다. |

합성 일정과 분리된 시험 서버로 검증한 뒤 통합 시험판에 반영한다.
