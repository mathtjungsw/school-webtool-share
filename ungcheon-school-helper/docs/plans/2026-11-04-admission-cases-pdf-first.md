# 수시모집 우수사례: PDF 기본 보기·정리 보기 상세 개선계획

- 작성일: 2026-11-04
- 현재 단계: **3. 테스트버전1.1.39-preview.1 개발·검증 완료**. [실제 구현·확인 범위와 제한](../testing/2026-11-04-grade-cases-preview.md)을 함께 확인한다. 아래 내용은 설계 기준이며 미검증 서식까지 완료로 뜻하지 않는다.
- 유지 범위: 로그인,0000 추가 잠금, 중앙 비공개 자료집, 로컬 암호화 캐시, 대학/학과/검색/필터/관심 저장, 이탈 시 재잠금.

## 1. 현재 문제

v1.1.38은 사례 선택 상태의 `original` 기본값이false라 지원현황·본문을 먼저 연다. 지원 표는 이미 일부 열로 나누지만 본문은 쪽 전체 텍스트를 `<pre>`에 그대로 표시한다. 페이지의 좌표·표 구조는 본문 저장 과정에서 제거되어 문단·병합 셀·항목 구분을 복원하기 어렵다. 지원 표의 행도 숫자 내신이 있는 줄을 중심으로 나눠 내신이 빈 행·여러 줄 학과/전형을 놓칠 수 있다.

## 2. 목표 화면과 기본 동작

상단에 `PDF 원문` / `지원현황·본문(정리 보기)` 두 전환 탭을 둔다. 기본 선택은 **PDF 원문**으로 고정한다.

1. 비밀번호를 해제하면 등록된 인문·자연 자료집과 왼쪽 사례 검색/목록, 오른쪽 PDF 영역을 표시한다.
2. 첫 이용 시 인문계열을 기본 권으로 열고 표지1쪽을 표시한다. 이후에는 마지막 선택한 권·쪽을 이 PC에서 복원할 수 있으나 기본 보기 방식은 계속 PDF로 시작한다.
3. 처음 여는 권·개정된 권만 중앙에서 내려받는다. 사용자가 선택하지 않은 권의 원문을 미리 받아오지 않는다.
4. 사례를 선택하면 해당 사례의 시작 쪽으로 이동하고 **PDF 원문 탭을 기본으로 표시**한다. 검색어로 진입하면 일치한 원문 쪽으로 이동하되 맥락 없는 자동 요약은 하지 않는다.
5. PDF에는 이전/다음 쪽, 직접 쪽 입력, 전체 쪽 수, 확대/축소, 너비 맞춤을 제공한다. 사례 범위와 자료집 전체 쪽 범위를 구분한다. PDF의 실제 쪽을 기준으로 이동한다.
6. 정리 보기에서 원문 탭으로 돌아가면 마지막 원문 쪽·확대율·스크롤 위치를 복원한다. 사례를 바꾸면 이전 사례의 원문이나 선택 상태가 뒤늦게 나타나지 않게 한다.
7. 화면이 좁으면 목록을 접거나 위쪽으로 바꾸어 PDF와 정리 표를 읽을 폭을 확보한다.

## 3. 지원현황·본문의 가독성 개선

### 3.1 지원현황 표

표 제목과 원문 쪽, 원문 확인 버튼을 함께 표시한다.

| 대학 | 모집단위·학과 | 전형 유형 | 세부 전형명 | 원문 내신 | 지원 결과 | 원문 |
| --- | --- | --- | --- | --- | --- | --- |
| 원문 값 | 원문 값 | 원문 값 | 원문 값 | 원문 표기 유지 | 원문 표기 유지 | 해당 쪽 이동 |

- 한 지원 건을 한 행으로 표시한다. 여러 줄 학과/전형은 셀 안 줄바꿈으로 보존한다.
- 내신 값이 없는 지원도 행을 누락하지 않는다. 공란·기호·해당 없음·읽기 실패를 구분한다.
- 대학별 환산 내신을 공통 내신으로 변환하지 않는다. 예비·합격·불합격 등 결과를 단어 경계로 해석하며 서로 다른 의미를 합치지 않는다. 색상과 글자를 함께 사용한다.
- 헤더 고정, 행 간격, 열 너비, 줄바꿈, 가로 스크롤로 긴 내용을 읽는다. 가로 스크롤 없이 값이 잘리도록 숨기지 않는다.
- 검색 필터는 같은 지원 행에서 대학·학과·전형·결과를 대조한다. 다른 지원 행의 값을 섞어 일치시켜서는 안 된다.

### 3.2 본문을 항목별로 정리

원문에 실제로 존재하는 항목만 표시하고, 없는 항목을 생성해 채우지 않는다.

| 원문 종류 | 표시 방식 |
| --- | --- |
| 학년별 성적 추이 | 원문 열과 단위를 보존한 표. 학년·학기 등 명시된 구분을 유지 |
| 지원학과 관련 과목 선택 | 일반/진로 등 원문 구분, 과목명·이수 정보를 행으로 표시 |
| 출결·학교생활 요약 항목 | 항목/원문 내용의2열 표 또는 짧은 정보 카드 |
| 창의적체험활동 | 원문 영역명·학년·내용의 표. 긴 서술은 셀 안 문단으로 분리 |
| 교과 세특 등 긴 기록 | 교과·과목·학년 등 원문 표제와 내용을 별도 카드/섹션에 배치 |
| 면접·후기·조언 | 원문에 존재할 때 제목과 문단/질문·답변 형태를 보존 |

본문 전체를 하나의 큰 표나 긴 텍스트 상자에 넣지 않는다. 긴 문장은 행간·문단 간격·최대 읽기 폭을 적용하고, 항목별 펼치기와 전체 펼치기/접기로 탐색한다. 검색어는 문맥 안에 강조하고 선택한 항목의 원문 쪽으로 이동할 수 있게 한다.

표 추출이 불확실한 곳은 `구조 확인 필요`를 표시하고 원문 표/해당 쪽을 바로 보여준다. 텍스트는 보조 보기로 제공하되 확정된 표로 오인하게 만들지 않는다. 원문 단어를 의미가 달라지게 재작성하거나 AI로 합격 사유·활동 내용을 생성하지 않는다.

## 4. 추출·데이터 구조 개선

- 기존 `pages[{page,text}]`에 더해 페이지 크기, 텍스트 좌표, 표 영역, 행/열/셀, 문단, 항목 제목, 출처 쪽과 추출 상태를 가진 구조를 만든다.
- 지원현황의 행은 숫자 내신을 기준으로 만들지 않고 표 경계·행 구간·병합 셀·여러 줄 텍스트로 복원한다.
- 다음 쪽으로 이어진 표와 사례 경계를 대조한다. 반복 헤더·각주·마지막 사례/부록을 잘못 합치지 않는다.
- 추출 성공 여부는 사례 전체의 단일true/false보다 항목·표·셀별로 보존한다. 원문에서 확인할 수 없는 값은 비워 두고 이유를 표시한다.
- 기존 캐시에 PDF 바이트가 있으므로 로컬 재판독으로 새 구조를 만든다. 새 추출기 버전만으로 중앙 PDF를 반복 다운로드하지 않는다. 원문 개정과 로컬 판독기 버전을 별도로 관리한다.
- 자료집·관심 사례의 안정적 ID를 유지해 원문 개정/재판독 시 관심 저장이 가능한 범위에서 이어지게 한다. 대응 불명확 시 다른 사례에 관심을 임의로 붙이지 않는다.
- 현재 원문 뷰어는 보고 있는 쪽과 인접 쪽만 렌더링하고 이전 작업은 취소한다. PDF 로딩·재판독·표 렌더링을 분리해 큰 자료집에서 앱 전체가 멈추지 않게 한다.

## 5. 개인정보·운영 비용

0000 해제 전에는 원문·썸네일·본문·관심 목록을 표시하지 않는다. 일반 로그아웃·120시간 만료·탭 이탈 때 원문 뷰와 렌더 작업도 잠근다. PDF와 텍스트·구조화 표·마지막 쪽·관심 데이터는 기존 로컬 암호화 범위에서 관리한다.

본문 추출·키워드 검색·표 구성은 PC에서 수행한다. 개인별 성적이나 검색어를 중앙 서버·외부 AI에 전송하지 않는다. 중앙 제공은 현재처럼 선택한 권의 개정이 달라진 경우에만 내려받는다. 새 서버·DB·유료 AI 서비스는 추가하지 않는다.

## 6. 수정 예정 파일

`privacy-parser.ts` 표·문단·항목 추출, `main.tsx` PDF 기본 진입/정리 보기/원문 위치 연결, `private.css` 읽기 폭·표·카드·반응형, `feature-views.ts` 암호화 캐시 스키마·재판독·권한·작업 취소, `workAssistantSearch.ts` 원문 우선 이용 순서를 수정한다. 서버 계약 변경은 필요성을 확인한 경우에만 최소 범위로 진행한다.

## 7. 검증·완료 기준

| ID | 확인할 내용 |
| --- | --- |
| SC2-01 | 최초 진입·다시 진입·사례 변경에서 PDF 원문이 기본 |
| SC2-02 | 첫 권·표지, 사례 시작 쪽, 검색 일치 쪽과 마지막 쪽 복원 |
| SC2-03 | 이전/다음·쪽 직접 입력·확대·너비 맞춤·빠른 연속 이동에서 쪽 혼선 없음 |
| SC2-04 | 정리 보기↔PDF 전환 때 현재 쪽·확대율·대상 사례 일치 |
| SC2-05 | 지원현황 복수 지원·빈 내신·여러 줄 학과/전형·병합 셀·예비 결과 전수 대조 |
| SC2-06 | 성적 추이·과목 선택·창체·세특 등 항목별 구조와 원문 수치/문장 보존 |
| SC2-07 | 다음 쪽 이어진 표·마지막 사례·부록·없는 항목·구조 불명확 안내 |
| SC2-08 | 같은 지원 행 검색·검색어 강조·본문 접기·표 가로 스크롤·좁은 화면 |
| SC2-09 | 기존 캐시 로컬 재판독·원문 개정 때만 다운로드·관심 사례 보존 |
| SC2-10 | 재잠금·로그아웃·만료·작업 취소에서 원문/표/임시 이미지 노출 없음 |
| SC2-11 | 두 권78개 사례의 범위와 지원 표·핵심 항목을 원문과 대조하고 미확인 상태 기록 |
| SC2-12 | 타입검사·기존 필수 검사·실제 Windows 시험 설치본에서 기본 PDF와 정리 보기 확인 |

실제 사례를 공개 테스트 픽스처나 안내 이미지에 넣지 않는다. 화면 검증에는 합성 사례를 사용하며, 원문 대조는 로컬에서 진행하고 보고서에는 집계·검증 범위만 남긴다.

## 8. 진행 순서

상세계획 저장(이번) → 사용자 다음 지시 후 PDF 기본/정리 보기 시안 → 시험판 구현·원문 대조·캐시 변환 검증 → 별도 정식 반영·배포 지시 후 적용. 이번에는 앱 소스·버전·설치파일·중앙 자료를 변경하지 않는다.
