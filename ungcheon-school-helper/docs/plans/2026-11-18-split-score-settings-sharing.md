# 12번 상세계획 · 추정분할점수 도우미 평가 설정 공유와 전체 이어하기

2026년 11월 18일 · PC판 · 전체 항목 검토 후 통합 시험판에서 검증

## 교사가 사용하는 방법

추정분할점수 도우미의 07 ‘다른 PC에서 이어서 하기’에서 다운로드를 누르면 아래 두 가지 중 하나를 선택한다. 열 때마다 ‘평가 설정만 공유하기’를 기본으로 표시한다.

| 선택 | 담을 내용 | 다른 업무도우미에서 열었을 때 |
| --- | --- | --- |
| **평가 설정만 공유하기** | 과목명, 학년·평가 방식, 시험·수행평가 이름·반영 비율·만점, 1·2차 문항 유형과 난이도별 배점, 목표 성취도 비율 등 평가 설정 | 새 과목 탭에 평가 구성이 채워진다. 학생 목록과 결과는 비어 있고, 받는 교사가 자기 자료를 올려 계산한다. |
| **학생 점수까지 담아 이어서 하기** | 현재 과목의 설정, 입력한 실제·예상 점수, 결시 상태, 계산 작업 | 저장 전에 ‘학생 이름과 점수가 포함될 수 있습니다.’를 표시한다. 새 과목 탭에서 마지막 작업을 이어간다. |

저장 창에서 파일명에 ‘설정공유’ 또는 ‘전체이어하기’를 표시한다. 두 파일 모두 기존 ‘업로드로 이어서 하기’ 버튼으로 연다. ‘이 PC에 저장’ 버튼과 2번 계획의 로컬 자동 암호화는 교사가 하던 작업을 보관하는 별도 동작이다. 내보내기와 불러오기도 PC에서 처리한다.

## 파일 생성과 복원

1. **설정 공유 파일은 허용한 필드로 새로 만든다.** 현재 전체 이어하기 파일에는 활성 평가 방식의 점수·결과 외에 다른 평가 방식으로 전환하기 전의 점수도 담길 수 있다. 설정 파일에는 각 방식의 평가 구성만 옮긴다. 학생 반·번호·이름, 점수, 결시, 석차, 개별 결과, 원본 파일 정보, 계산 완료 표시·시각은 기록하지 않는다. 2차 문항 구성이 1차 배점을 따르는 설정과 2차에서 따로 수정한 설정을 구분해 복원한다.
2. **파일에 종류와 형식 버전을 기록한다.** 첫 안내 시트와 파일명에서 교사가 종류를 알아볼 수 있게 한다. 앱은 내부 형식을 확인해 설정 파일에는 설정 전용 읽기 절차를 적용한다. 학생 자료가 섞여 형식과 맞지 않으면 가져오기를 중단하고 이유를 안내한다.
3. **기존 전체 이어하기 파일을 계속 읽는다.** 종류 표시가 없는 기존 엑셀은 기존 필수 시트와 열을 확인해 전체 이어하기 방식으로 연다. 전체 파일은 0점·결시·미입력과 실제·예상 점수의 구분을 복원한다. 계산한 작업은 기존 계산 방식에 따라 복원 결과를 대조하고, 계산 전 작업은 그대로 이어갈 수 있게 한다.
4. **현재 과목을 보호한다.** 읽기와 검증을 마친 파일만 새 과목으로 저장하고 탭을 연다. 같은 이름의 과목이 있어도 기존 과목을 덮어쓰지 않는다. 파일 선택 취소, 형식 오류, 저장 실패 시 사용 중인 과목과 목록을 보존한다.

점검한 소스는 `src/pages/EstimatedSplitScorePage.tsx`의 07 화면과 `src/services/gradePreview.ts`의 이어하기 엑셀 생성·복원 함수다.

## 통합 시험판 합격 기준

| 상황 | 확인할 결과 |
| --- | --- |
| 가상 학생과 성적을 두 평가 방식에 각각 넣고 설정 공유 파일 생성 | 모든 시트·공유 문자열·내부 데이터에서 시험용 학생 식별 표식이 발견되지 않는다. 점수·결시·개인 결과를 담는 행과 필드도 없다. 원래 과목의 점수는 남아 있다. |
| 설정 파일을 다른 시험 프로필로 불러오기 | 과목명·평가 구성·반영 비율·배점·목표 비율이 원래 입력과 일치한다. 학생 수는 0명이고 계산 전 상태다. 새 합성 성적 파일을 올려 계산할 수 있다. |
| 전체 파일에 실제·예상 점수, 0점·결시·미입력, 이전 평가 방식의 점수를 넣어 왕복 | 새 과목에서 상태와 수치가 입력값과 일치한다. 계산한 자료는 학생별 결과를, 아직 계산하지 않은 자료는 계산 전 상태를 확인한다. |
| 기존판 전체 파일·이름이 같은 과목·잘못된 파일로 각각 가져오기 | 기존 파일은 새 탭에서 열리고 이전 과목은 유지된다. 설정 전용 형식에 학생 자료가 섞인 파일이나 손상 파일은 오류 이유를 보여 주며 과목 목록을 바꾸지 않는다. |

검증은 가상 학생 자료와 분리된 로컬 프로필에서 진행한다.
