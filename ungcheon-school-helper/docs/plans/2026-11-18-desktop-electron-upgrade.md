# 16번 상세계획 · PC판 내장 브라우저(Electron) 업데이트

2026년 11월 18일 · PC판 · 전체 항목 검토 후 통합 시험판에서 검증

## 출발점과 버전 선택

현재 프로젝트의 PC판 1.1.43은 Electron 31.7.7을 사용한다. Electron 31의 공식 지원은 2025년 1월 14일 종료됐다. 2026년 11월 18일 기준 45 계열을 첫 검토 대상으로 삼고, 시험판 제작 시점에 공식 지원 중인 안정 계열과 패치 버전을 다시 확인해 정확한 버전을 고정한다. 학교 PC에서 사용하는 Windows 버전과 x64 설치 환경을 확인하고 학교망 프록시·인증서 처리, 문서 열람·인쇄, 기존 설치본에서의 업데이트 결과를 함께 기록한다. [Electron 공식 지원 일정](https://releases.electronjs.org/schedule)

## 개발 순서

1. 현재 설치형 앱을 기준으로 가상 교직원 계정, 여러 과목의 합성 성적 작업, 가상 PDF, 위젯 설정을 준비한다. 같은 Windows 계정에서 같은 입력과 설치 경로로 전후를 비교할 수 있게 시험용 프로필과 스냅샷을 남긴다.
2. 공식 주요 변경사항을 버전 순서대로 검토한다. 본창·위젯 생성, 외부 웹앱 표시, 학교망 통신, Windows 암호화 저장, PDF 작업과 자동 업데이트에 쓰는 API를 먼저 대조한다. 기존 빌드·설치 도구와 호환되는지 확인하고, 호환을 위해 필요한 도구와 의존성만 함께 갱신한다. 외부 웹앱 분리와 보호 자료 열람 검사를 새 버전에서도 적용한다. [Electron 주요 변경사항](https://www.electronjs.org/docs/latest/breaking-changes)
3. 기존 타입 검사와 로그인·위젯·업데이트 검사를 실행한 뒤 Windows x64 NSIS 설치파일로 새 설치와 기존판 위 설치를 각각 확인한다. 앱 식별자, 사용자 자료 위치, 위젯 자동 시작과 바로가기가 기존 설치자의 환경을 이어받는지 본다.

## 사용 흐름별 시험 기준

| 흐름 | 합격 기준 |
| --- | --- |
| 학교망 로그인과 웹앱 이용 | 시험 계정으로 학교망에서 로그인하고 재실행 후 세션을 복원한다. 생기부 도우미와 웅천 서가의 첫 화면이 열리고, 법정의무연수 두 버튼을 오갈 수 있다. 시험용 이수증 자료로 다운로드 창과 파일 저장을 확인한다. |
| 업데이트 전 작업 이어가기 | 같은 Windows 계정에서 기존판에 넣어 둔 가상 성적 자료와 추정분할점수 과목을 업데이트 뒤 다시 연다. 학생 수·점수·결시 상태·반영 비율을 대조하고 마지막으로 작업한 과목을 확인한다. PDF 원문을 열어 페이지를 넘기고 시험 문서를 인쇄한 결과의 한글과 쪽 수를 확인한다. |
| 위젯에서 업데이트하기 | 위젯만 실행한 상태에서 ‘업데이트 지금하기’를 누른다. 본창에서 추가 조작할 필요 없이 다운로드·설치·재시작을 마치고, 재실행된 앱의 버전과 위젯의 시간표·위치 설정을 확인한다. 다운로드가 중단된 경우 기존판을 다시 쓸 수 있고 재시도 뒤 설치가 한 번만 이루어져야 한다. |

## 업데이트 검증 환경과 복구

- 일반 시험판의 업데이트 시뮬레이션은 버튼과 진행 상태 확인에 사용한다. 실제 설치·재시작은 별도의 Windows 시험 환경에서 기존판을 바탕으로 한 설치본과 새 설치본을 같은 시험용 앱 식별자·로컬 업데이트 경로로 연결해 확인한다. 이 환경에서는 실제 업데이트 코드와 NSIS 설치기를 사용하고 운영 GitHub 릴리스와 교직원 PC에는 연결하지 않는다.
- 앱 시작 실패, 성적 복원 불일치 또는 위젯 업데이트 중단을 재현하면 시험 환경을 이전 스냅샷으로 복구해 원인을 좁힌다. 저장 형식이 달라진 경우에는 구버전 앱을 새 자료에 바로 덮어씌우지 않고, 스냅샷에 보관한 시험용 자료로 복구를 확인한다.
- 검증 기록에는 기존판·시험판 버전, Windows 버전, 학교망에서 실제로 확인한 항목, 설치·재시작 결과를 구분해 적는다. 11번에서 정한 위젯·본창 시작 시간 측정도 같은 환경에서 진행한다. [11번 시작 속도 개선계획](2026-11-18-desktop-widget-startup.md)
