# 6번 상세계획 · 모바일 주간 일정 탭 통합

2026년 11월 18일 · 상세계획 작성 완료 · 전체 항목 검토 후 통합 시험판 제작

## 교사가 보는 화면

모바일 상단에는 ‘날짜’, ‘주간 시간표’, ‘주간 일정’을 이 순서로 표시한다. 기존에 따로 있던 ‘이번 주’와 ‘다음 주’ 일정 목록은 ‘주간 일정’에서 한 번의 터치로 전환한다.

| 상단 탭 | 처음 보이는 화면 | 이동 방법 |
| --- | --- | --- |
| 날짜 | 앱을 열면 오늘 수업·일정·급식을 표시한다. | 기존 날짜 선택 기능으로 다른 날을 연다. |
| 주간 시간표 | 요일과 교시에 맞춘 교사 수업표를 표시한다. | 기존 지난주·이번 주·다음 주 이동을 유지한다. |
| 주간 일정 | 처음 들어가면 이번 주 월요일부터 일요일까지의 일정을 날짜순으로 표시한다. | 목록 바로 위에 ‘이번 주’, ‘다음 주’ 버튼과 선택한 실제 날짜 범위를 표시한다. 토요일·일요일도 포함한다. |

예를 들어 2026년 11월 18일에 ‘주간 일정’을 열면 ‘이번 주 · 11월 16일~11월 22일’이 보인다. ‘다음 주’를 누르면 같은 자리에서 ‘11월 23일~11월 29일’ 일정으로 바뀐다. 현재 선택은 글자·버튼 모양과 접근성 상태로 표시한다. 날짜 화면에서 다음 주 일정으로 가는 경로는 ‘주간 일정 → 다음 주’ 두 번이다.

## 구현과 데이터 조회

- 기존 주간 목록·일정 상세보기·종류 필터·새 일정 표시를 재사용한다. 같은 앱 사용 중에 다른 탭을 잠시 열었다가 돌아오면 선택했던 주를 유지하는 것을 기본으로 한다. 앱을 새로 시작하면 ‘날짜’에서 시작한다. 주간 일정의 주 선택과 주간 시간표의 주 선택은 독립적으로 관리한다.
- 날짜 범위는 학교 기준 시각으로 계산한다. 일요일에서 월요일로 넘어가면 이번 주·다음 주가 가리키는 기간, 화면 제목, 조회 기간을 함께 갱신한다. 월·연도가 달라지는 주도 시작일과 종료일을 알아볼 수 있게 표시한다.
- [4번 상세계획](2026-11-18-mobile-today-first.md)의 조회·캐시를 사용한다. 오늘 화면에서는 주간 목록을 미리 받지 않는다. 주간 일정을 열면 선택한 기간만 확인하고, 이미 받은 날짜와 자료는 재사용한다. 다음 주와 이번 주를 빠르게 오가도 늦게 도착한 응답을 다른 주 제목 아래 표시하지 않는다.
- 조회 중·미조회·정상 조회 결과 일정 없음·이전 자료를 화면에서 구별한다. 휴대전화의 좁은 화면에서도 세 상단 탭과 기간 선택 버튼을 읽고 누를 수 있게 한다. 읽기 도구가 상단 탭과 주 선택 버튼, 선택된 기간을 구별할 수 있는지 확인한다.
- 모바일 화면과 이를 설명하는 앱 내 안내에서 예전 네 탭 표기를 찾아 세 탭 구성으로 갱신한다. PC 캘린더·위젯과 공용 서버의 권한·출결 계약은 그대로 사용한다.

## 시험판 합격 기준

1. 새로 열면 ‘날짜’가 선택되고, 첫 화면의 주간 일정 본문 요청은 0건이다. 주간 일정에 처음 들어가면 이번 주를 표시하고, 다음 주를 한 번 눌러 날짜 범위와 목록을 함께 바꿀 수 있다.
2. 두 주의 날짜별 일정, 주말 행사, 일정 상세와 필터 적용 결과가 통합 전 같은 기간의 결과와 일치한다. 주간 일정에서 다음 주를 선택해도 주간 시간표의 주 위치는 바뀌지 않는다.
3. 동일 기간 재선택, 급속 전환, 느린 응답과 오프라인 상황에서 다른 주 일정이나 잘못된 ‘일정 없음’이 나타나지 않는다. 캐시가 있는 기간의 정상 자료는 계속 표시한다.
4. 작은 모바일 화면과 글자 확대 상태에서 탭과 날짜 범위가 잘리지 않는다. 주간 일정의 두 기간 버튼과 주간 시간표의 이전·다음 주 버튼을 각각 독립적으로 조작할 수 있다. 한국 기준 주·월·연도 경계에서 표시 범위와 조회 범위가 일치한다.
