# 13번 상세계획 · 수시모집 우수사례 열람을 학교 서버에서 확인하기

2026년 11월 18일 · PC판 진학·대입 · 전체 항목 검토 후 통합 시험판에서 검증

## 교사가 사용하는 순서

1. ‘진학·대입 → 수시모집 우수사례’를 열고 기존에 안내받은 추가 비밀번호를 한 번 입력한다. 서버가 현재 교직원 로그인과 추가 비밀번호를 확인한 뒤 기본 화면인 PDF 뷰어를 연다.
2. 같은 탭 안에서 대학·학과별 목록, 가나다 색인, 검색, 관심 사례, 지원 현황, 본문과 PDF를 오갈 수 있다. 자료집이나 페이지를 바꿀 때 비밀번호를 다시 묻지 않는다.
3. 다른 메뉴로 이동해 탭을 닫으면 즉시 잠근다. 다시 열 때에는 추가 비밀번호를 확인한다. 앱 로그아웃, 로그인 사용자 변경, 120시간 세션 만료 때에도 열람을 종료한다. 우수사례 열람이 앱 로그인 만료 시각을 연장하지 않는다.

## 서버 확인과 PC 사본 사용

- **현재 동작.** PC의 보호 화면이 추가 비밀번호를 비교하고, 학교 서버는 교직원 로그인만 확인한 뒤 자료집 목록이나 문서를 제공한다. 점검한 소스는 `electron/main/feature-views.ts`와 `server/StaffAuth.gs`이다.
- **열람 시작.** 추가 비밀번호의 검증값은 학교 서버에서 관리한다. 성공하면 서버는 현재 교직원 로그인과 이번 탭 열람에만 쓸 수 있는 임시 권한을 발급한다. PC는 이를 실행 중인 메모리에만 둔다. 목록과 PDF를 제공하는 서버 경로에도 열람 확인을 적용한다. 확인 전에는 제목, 검색 결과, 관심 사례, 이전에 보던 PDF를 표시하지 않는다.
- **같은 자료 다시 열기.** 서버가 이번 열람에 허용한 자료의 식별자와 버전을 알려 주면 PC가 해당 사본과 대조한다. 버전이 같고 읽을 수 있는 문서는 본문을 다시 받지 않는다. 변경됐거나 사본이 없거나 손상된 경우에만 선택한 자료를 받는다. PDF와 검색용 색인은 같은 버전을 사용한다. 서버 목록에서 제외된 자료는 옛 사본이 있어도 열지 않는다.
- **연결 실패.** 탭을 열 때 서버 확인에 실패하면 ‘학교 서버에 연결할 수 없습니다’와 ‘연결 다시 확인’을 표시하고 기존 사본은 잠근다. 비밀번호 불일치는 탭 안에서 다시 입력하도록 안내하고, 앱 로그인 자체가 만료된 경우에는 로그인 화면으로 이동한다.
- **열람 종료.** 화면에서 PDF와 검색 결과를 즉시 닫고 메모리의 열람 권한과 문서 참조를 정리한다. 늦게 도착한 목록·문서 응답과 PDF 분석 결과는 폐기한다. 서버에도 이번 열람 종료를 알리고, 앱 비정상 종료나 통신 단절로 종료 통지가 도착하지 않아도 임시 권한에는 서버 측 만료 시각을 둔다. 다음 탭은 새로 확인한다. PC 사본을 직접 삭제하는 기능은 [8번 저장자료 관리 계획](2026-11-18-local-data-management.md)을 따른다.

## 통합 시험판 합격 기준

| 시험 상황 | 확인할 결과 |
| --- | --- |
| 자료를 받은 적 없는 PC와 이전 버전 사본이 남아 있는 PC에서 각각 탭 진입 | 추가 확인 전에는 두 PC 모두 잠금 화면만 보인다. 확인 실패 시 제목·본문·검색 결과가 표시되지 않는다. 서버도 미확인 세션에 목록과 문서를 제공하지 않는다. |
| 올바른 비밀번호로 열고 PDF → 대학별 → 학과별 → 검색 → 본문 이동 | 추가 입력은 한 번이다. PDF가 먼저 열리며, 검색한 사례의 본문과 원문 페이지가 같은 자료를 가리킨다. |
| 같은 버전·바뀐 버전·열람 목록에서 제외된 자료로 재진입 | 같은 버전 PDF 본문 다운로드는 0건이다. 변경된 문서는 선택 시 새 버전으로 갱신되고, 제외된 문서는 PC 사본으로 열리지 않는다. |
| 사본이 있는 PC에서 망 단절 상태로 탭 진입 후 연결 복구 | 사본은 잠겨 있고 ‘연결 다시 확인’이 보인다. 연결 복구와 서버 확인 후에만 열리며 정상 사본을 재사용한다. |
| 문서를 읽는 도중 탭 닫기, 로그아웃, 사용자 변경, 세션 만료를 각각 재현 | 열려 있던 원문과 검색 결과가 사라진다. 이전 응답이 늦게 와도 다시 표시되지 않으며 다음 사용자는 추가 확인을 거친다. |

분리된 시험 서버와 가상 교직원·모의 PDF로 두 PC 상태를 재현한다. 기존 버전 앱으로도 서버가 추가 확인을 요구하는지 검사하고, 정식 전환 때에는 구버전 사용자에게 업데이트 경로를 안내한다.
