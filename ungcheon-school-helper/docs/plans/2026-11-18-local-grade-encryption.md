# 2번 상세계획 · 성적 자료의 로컬 자동 암호화 및 복원

2026년 11월 18일 · 상세계획 작성 완료 · 전체 항목 검토 후 통합 시험판 제작

## 교사가 사용하는 방법

교사 한 명이 자신의 PC와 Windows 계정을 사용한다. 기존 방식으로 업무도우미에 로그인해 성적 메뉴를 열면 마지막으로 저장한 작업이 자동 복호화되어 나타난다. 성적용 비밀번호나 PIN을 만들거나 입력하는 단계는 두지 않는다.

| 도구 | 자동 저장·복원할 작업 |
| --- | --- |
| 평균내신등급 산출기 | 기존 암호화 자료 및 PDF 페이지 연결을 그대로 읽는다. 자료를 등록하거나 학생 정보·과목·학점·등급을 수정하면 변경 내용을 자동 저장한다. |
| 등급 미리보기 | 평가 구성, 학생별 실제 점수·결시 상태, 계산 설정과 계산 작업 상태를 복원한다. |
| 추정분할점수 도우미 | 과목 목록·순서·선택한 과목, 과목별 실제·가상 점수, 반영 비율, 목표 분포, 문항 설정 및 저장된 계산 결과를 복원한다. |

## 저장과 불러오기

- PC의 기존 평균내신 저장 코드에서 사용하는 Windows 보안 저장소와 인증 암호화 방식을 재사용한다. 파일을 쓰기 전에 앱 내부에서 암호화하고 키는 Windows 사용자 계정으로 보호한다. 앱이 이미 성적 저장을 끝낸 상태에서는 해당 Windows 계정과 유효한 앱 로그인으로 성적 화면을 열 수 있다는 보안 범위를 전제로 한다.
- 기존 앱 로그인 상태를 성적 조회·저장 요청에서도 확인한다. 복호화한 내용은 사용 중인 성적 화면과 필요한 로컬 처리 메모리에만 둔다. 로그아웃·세션 만료 시 화면과 열람 데이터를 정리하고, 뒤늦게 도착한 응답으로 다시 표시되지 않게 한다.
- 짧은 연속 입력은 묶어서 저장하고 과목 전환·화면 이동·정상 종료 직전에는 남은 변경을 마무리한다. 먼저 시작한 저장이 나중 수정을 덮지 않도록 쓰기 순서를 관리한다. 기존 ‘저장’ 버튼도 같은 저장 경로로 즉시 반영한다. 암호화가 끝난 임시 사본을 검증한 뒤 마지막 정상 파일을 교체한다.
- 성적 화면을 열면 기존 작업을 먼저 읽고 나서 자동 저장을 시작한다. 불러오기 실패나 Windows 암호화 사용 불가 시 마지막 정상 자료를 보존하고 ‘불러오기 실패’ 또는 ‘저장되지 않음’과 재시도 방법을 표시한다. 오류를 빈 작업으로 간주하거나 평문 저장으로 대체하지 않는다.
- 성적 PDF·Excel과 학생별 결과를 읽거나 처리하는 과정에서 성적 내용·원본·키를 GitHub, 학교 서버, 외부 AI나 진단 로그로 보내지 않는다. 선택한 원본 파일은 원래 위치에 그대로 둔다. 이번 자동 암호화는 앱이 보관하는 사본과 작업 데이터에 적용한다. 기존의 ‘이어서 하기’ 파일을 교사가 직접 내보내고 가져오는 흐름은 별개이며, 내보낸 파일의 보호 방식은 별도 검토한다.

## 기존 자료 이전과 삭제

업데이트 후 첫 사용 시 기존 등급 미리보기 초안, 구버전의 두 도구 통합 자료, 추정분할점수의 여러 과목과 과목별 설정을 찾아 이 PC에서 자동 이전한다. 새 암호화본을 다시 읽어 과목·학생·점수와 누락값까지 대조한 뒤 성공한 항목의 기존 브라우저 저장 데이터만 지운다. 기존 자료와 새 자료가 서로 다른 경우 양쪽을 보존한다. 중단 후 다시 실행해도 같은 과목이 중복되거나 정상 자료가 덮이지 않아야 한다. 평균내신에 이미 보관된 암호화 파일과 원문 연결의 호환성을 유지한다.

성적 도구에서 사용자가 자료 비우기를 확정하면 해당 도구의 저장 자료와 대기 중인 자동 저장을 함께 정리한다. 다른 성적 도구, 다른 과목의 유지 대상 자료, 사용자가 처음 선택한 외부 파일은 보존한다. 설정의 공유자료 캐시 삭제는 성적 초안에 영향을 주지 않는다.

## 시험판 합격 기준

1. 세 도구에서 가상 학생의 점수·설정을 수정하고 앱을 정상 종료한 뒤 같은 Windows 계정에서 재실행한다. 기존 앱 로그인 절차만 거쳐 마지막 수정 값이 복원된다.
2. 여러 과목을 빠르게 전환하거나 입력 직후 창을 닫아도 과목별 값이 섞이지 않는다. 자료 비우기 이후 메뉴 재진입·재실행으로 삭제한 자료가 되살아나지 않는다.
3. 구버전 단일·다중 과목, 결시·0점·미입력, 기존 평균내신 PDF 페이지 연결을 포함한 합성 자료로 이전 전후를 대조한다. 이전 중 중단 후 재시도까지 확인한다.
4. 키 사용 불가, 디스크 저장 실패, 손상된 파일을 재현한다. 정상 사본 보존, 오류 표시, 읽기 실패 후 빈 값 자동 덮어쓰기 방지를 확인한다.
5. 합성 학생의 고유 표식을 이용해 앱이 만든 영구 저장 파일·브라우저 저장소·로그·요청에 성적 평문이 남거나 전송되지 않는지 검사한다. 기존 원본 및 사용자가 명시적으로 내보낸 파일은 검사 범위에서 구분한다. 다른 Windows 계정에서 암호화 파일과 보호된 키 사본만으로 열리지 않는지도 확인한다.
