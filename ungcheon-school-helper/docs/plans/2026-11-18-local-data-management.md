# 8번 상세계획 · 이 PC의 저장자료 관리

2026년 11월 18일 · PC판 · 상세계획 작성 완료 · 전체 항목 검토 후 통합 시험판 제작

## 1. 화면과 삭제 범위

설정의 ‘로컬 저장자료 모두 삭제’를 ‘이 PC의 저장자료 관리’로 바꾼다. 항목별로 저장 여부, 확인 가능한 마지막 저장 시각, 삭제 범위와 다시 받을 수 있는지를 표시한다. 목록을 표시하려고 학생 이름이나 점수, 우수사례 본문을 읽지 않는다.

| 항목과 버튼 | 지우는 범위 | 교사에게 안내할 복구 방법 |
| --- | --- | --- |
| 학교 공유자료 · ‘공유자료 캐시 비우기’ | 이 PC에 내려받은 로그인 사용자의 명렬·시간표 등 학교 공유자료 사본과 해당 메모리 캐시 | 다음에 자료가 필요할 때 현재 조회 권한으로 학교 서버에서 다시 받는다. 인터넷 연결이 필요하다. |
| 평균내신등급 산출기 · ‘산출기 자료 비우기’ | 산출기 안에 저장된 학생·성적·과목 수정 내용, 원문 보기용 사본과 이전 형식의 내부 보관본 | 처음 선택한 PDF·Excel로 다시 계산할 수 있다. 앱에서 직접 수정한 값은 별도로 보관한 자료가 있어야 되살릴 수 있다. |
| 등급 미리보기 · ‘등급 미리보기 작업 삭제’ | 해당 도구의 입력 점수, 평가 구성 및 로컬 작업 상태 | 서버 자동 복원이 없다. 원본을 다시 올리면 새 작업으로 시작한다. |
| 추정분할점수 도우미 · ‘선택한 과목 삭제’ | 고른 과목 하나의 점수·배점·목표 분포·문항 설정·계산 상태와 과목 목록의 해당 항목 | 교사가 미리 내려받은 이어하기 파일이 있다면 그 파일을 직접 불러올 수 있다. 다른 과목은 계속 이용한다. |
| 수시모집 우수사례 · ‘내려받은 사례 자료 비우기’ | 이 PC에 보관된 문서 사본과 문서에서 만든 검색·열람 데이터 | 서버 자료가 있고 열람 권한이 있으면 다시 받는다. 관심 표시 등 개인 설정은 문서 사본과 별도로 보존한다. |

이 기능이 다루는 범위는 앱이 관리하는 저장공간이다. 교사가 선택했던 원본이나 문서 폴더에 직접 저장한 이어하기·내보내기 파일은 대상에 포함하지 않는다. 공유자료와 우수사례를 정리해도 성적 초안이나 앱 로그인 상태에는 영향이 없다.

## 2. 교사의 조작 순서

1. 설정에서 자료 종류를 고른다. 저장된 자료가 없으면 ‘저장된 자료 없음’을 표시한다. 추정분할점수는 과목을 명시적으로 고르게 하고, 삭제 직전에는 선택한 과목의 실제 이름을 표시한다.
2. 다시 받을 수 있는 캐시는 해당 항목의 비우기 버튼으로 정리한다. 성적 작업은 확인창에서 도구명·대상·복구 가능 여부를 보고 최종 결정한다. 예를 들어 “추정분할점수의 ‘수학Ⅰ’ 작업을 지울까요? 처음 올린 엑셀 파일은 그대로 남습니다. 이어하기 파일을 따로 보관했다면 다시 불러올 수 있습니다.”로 안내한다. 기본 선택은 ‘취소’, 실행 버튼은 ‘수학Ⅰ 작업 삭제’처럼 대상을 적는다.
3. 삭제가 끝나면 실제 결과를 다시 조회해 해당 항목만 비어 있음을 표시한다. 마지막 과목을 지웠다면 ‘과목 추가’로 새 작업을 시작할 수 있게 하고, 기존 과목이 삭제 직후 기본값으로 복원되지 않도록 한다.
4. 평균내신 화면의 기존 ‘비우기’는 설정에서 해당 항목을 선택한 것과 같은 확인·삭제 절차를 사용한다. 업무 검색의 ‘로컬 자료 삭제’, ‘성적 비우기’ 안내도 새 위치와 범위에 맞춘다.

## 3. 구현할 때 지킬 조건

- [1번 명렬·시간표 동기화](2026-11-18-private-rosters-timetables.md)와 [2번 성적 로컬 자동 저장](2026-11-18-local-grade-encryption.md)의 저장 범위를 재사용한다. 도구별로 허용된 자료와 내부 과목 ID를 확인한 뒤 삭제한다. 같은 이름의 과목이 있어도 다른 과목을 지우지 않는다.
- 삭제를 시작하면 해당 대상의 대기 중인 저장·이전·다운로드 요청을 무효화한다. 삭제 전 요청이 늦게 도착해도 디스크나 화면에 다시 쓰지 못하게 한다. 본창·위젯과 문서 뷰어도 메모리 사본을 비운다. 이후 사용자가 자료를 열거나 정상 동기화가 새로 실행되어 다시 내려받은 캐시는 새 수신으로 구분한다.
- 이전 버전의 평문 초안, 암호화본, 복구용 내부 사본이 공존하면 같은 대상인지 확인해 함께 정리한다. 구형 저장 키를 두 도구가 사용한 경우 데이터 구조로 소유 도구를 판별한다. 판별이 어려운 자료는 보존하고 결과를 알린다. 다른 과목에서도 사용하는 암호화 키는 유지한다.
- 우수사례 자료 비우기는 문서 내용을 열어 보여 주지 않는다. 다시 열람할 때 기존 로그인·추가 열람 확인을 적용한다. 앱 밖의 경로나 서버 원본을 지우는 기능과 연결하지 않는다.
- 도중에 파일이 잠기거나 저장공간에 접근하지 못하면 ‘일부 자료가 남아 있습니다’와 재시도 동작을 표시한다. 삭제를 다시 눌러도 앞서 정리한 자료나 다른 항목에는 영향이 없어야 한다.

## 4. 시험판 합격 기준

| 가상 자료로 시험할 상황 | 통과 조건 |
| --- | --- |
| 공유자료·성적·우수사례가 모두 있는 PC에서 공유자료만 비우기 | 내려받은 명렬·시간표만 정리된다. 학교 원본, 성적, 사례와 로그인은 유지된다. 다시 조회하면 권한 범위의 최신 자료를 받는다. |
| 두 성적 도구와 추정분할점수 두 과목을 함께 저장 | 추정분할점수 한 과목만 지운 뒤 재실행해도 선택한 과목만 사라진다. 다른 과목의 입력값, 다른 도구의 점수, 원본 파일과 내보낸 파일은 그대로다. |
| 성적 확인창에서 취소 / 마지막 과목 삭제 | 취소하면 값이 바뀌지 않는다. 마지막 과목 삭제 후에는 빈 상태에서 새 과목을 추가할 수 있다. |
| 성적 자동 저장 중 삭제 / 구형 초안 이전 직후 삭제 | 늦은 저장 완료, 메뉴 재진입, 앱 재실행 후에도 지운 작업이 복원되지 않는다. 성공 시 해당 범위의 앱 내부 원문 사본·구형 초안도 남지 않는다. |
| 평균내신 메뉴에서 비우기 / 설정에서 비우기 | 어느 경로든 같은 범위와 같은 결과를 안내하며, 선택했던 PDF·Excel은 계속 열 수 있다. |
| 우수사례를 열어 둔 채 문서 사본 비우기 | 화면·로컬 검색 결과에서 사본이 사라지고 서버 자료와 관심 표시는 유지된다. 오프라인에서는 다시 받기가 필요하다고 표시하며, 온라인에서 권한을 확인한 뒤 다시 볼 수 있다. |
| 파일 잠금과 중간 실패 | 일부만 지운 경우 완료로 표시하지 않는다. 남은 대상만 다시 정리할 수 있고 다른 자료는 유지된다. |
