# 평균내신등급 산출기: PDF 판독·학생 검색 상세 개선계획

- 작성일: 2026-11-04
- 현재 단계: **3. 테스트버전1.1.39-preview.1 개발·검증 완료**. [실제 구현·확인 범위와 제한](../testing/2026-11-04-grade-cases-preview.md)을 함께 확인한다. 아래 내용은 설계 기준이며 미검증 서식까지 완료로 뜻하지 않는다.
- 기준: 정식 v1.1.38. 기존 PDF/XLSX 입력, 두 교과 범위, 학점 가중평균, 로컬 암호화 저장·비우기를 보존한다.

## 1. 해결할 문제와 우선순위

34쪽 예시의 석차등급 표 63행 중 현재 판독기는56행을 읽는다. 두 줄 과목명 때문에7행이 누락된다. 먼저 성적 행과 원본의 대응을 바로잡고 학생 검색을 붙인다. 오류가 있는 행을 감춘 채 검색 기능만 추가하지 않는다.

1. 과목 셀·표 행을 복원해 과목·학점·등급 누락을 해결한다.
2. 학생을 학번·학년·반·번호·이름으로 독립적으로 저장하고 검색한다.
3. 선택한 한 학생의 평균, 반영 과목과 확인 필요 항목을 즉시 확인한다.

## 2. PDF 판독 개선

### 2.1 표와 행을 기준으로 읽기

- 교과학습발달상황의 표 영역을 먼저 식별한다. 본문·세특·쪽 머리말·서명·날짜는 성적 표 밖의 데이터로 분리한다.
- 교과/과목/학점/석차등급 등 헤더를 여러 줄에 걸쳐 합쳐 열을 정한다. `석차`와 `등급`이 위아래로 나뉜 헤더도 지원한다.
- 표 선이 있으면 선·셀 경계를 활용하고, 없으면 열 위치와 행 간격·학점/등급 셀의 범위를 조합해 행 구간을 만든다. PDF.js가 제공하는 선/텍스트 정보로 우선 구현하고, 부족한 서식은 대조용 셀 추출 방식과 비교한다.
- 과목명은 같은 y 한 줄이 아니라 **같은 과목 셀의 위~아래 범위 전체**에서 읽어 순서대로 결합한다. 공백 포함 원문 표시명과 검색용 정규화명을 따로 둔다. 사전에 없는 과목을 비슷한 과목으로 자동 치환하지 않는다.
- 과목명·학점·석차등급은 같은 표의 같은 행으로 연결한다. 원점수/과목평균·성취도·수강자 수를 학점이나 석차등급으로 잘못 쓰지 않는다.
- 학기·교과의 병합 셀은 실제 병합 범위 안에서만 내려 채운다. 새 학생·새 학년·학기·표에서 상태를 초기화한다.
- 다음 쪽의 이어진 표는 같은 학생·학년·표 구조가 확인될 때만 연결하고, 반복 헤더·학점 합계·세특 행은 과목 행으로 추가하지 않는다.
- 문서 전체가 스캔이거나 글자층이 비정상인 경우를 구분한다. 로컬 OCR은 정확도·처리시간을 별도 검증한 보조 경로로 검토하고, 확신이 낮으면 XLSX 또는 수동 확인을 안내한다. 외부 AI/OCR 서버로 학생부를 전송하지 않는다.

### 2.2 누락과 무등급을 구분

판독 행에는 `확인 완료 / 확인 필요 / 원문상 무등급 / 지원하지 않는 표` 등의 상태와 사유를 둔다. 석차등급 칸이 원문상 비어 있는 것과 칸을 읽지 못한 것을 구분한다.

업로드 결과에 문서 쪽 수·학생 수·표 과목 수·반영 가능 수·정상 제외 수·확인 필요 수를 표시한다. 과목명이 없다고 행을 조용히 삭제하지 않는다. 표에서 발견한 행과 생성한 행의 수가 다르면 확인을 요구한다.

확인 필요 과목이 남으면 평균은 `확인 전 임시 결과`로 표시하고 확정 표시를 하지 않는다. 실패한 학점을1로 채우거나 성취도를 등급으로 환산하지 않는다. 기존 산식은 유지한다.

`석차등급 있는 과목의 Σ(학점×등급) ÷ 같은 과목의 Σ학점`

### 2.3 원문 대조·수정

과목 행에 파일·쪽·표·셀 위치를 저장한다. 과목을 누르면 해당 학생의 원문 쪽과 표 영역을 로컬에서 보여준다. 과목명·학년·학기·교과·학점·등급을 수정하고 원문 값/수정 값/확인 상태를 보존한다. 파일은 기존 격리된 로컬 보기에서 열고 임의 파일 경로를 IPC로 받지 않는다.

## 3. 학생 식별과 필터

### 3.1 학생 데이터 구조

성적 행의 `student` 표시 문자열과 별개로 학생 목록을 만든다.

| 정보 | 처리 기준 |
| --- | --- |
| 내부 학생 ID | 표시명·파일명과 분리한 안정적 ID. 학생별 성적 행이 이 ID를 참조 |
| 학번 | 원문 문자열 보존. 앞자리0을 지우지 않으며 이름이나 파일 순번으로 생성하지 않음 |
| 재학 학년·반·번호 | 학생 검색용 소속 정보. 성적의 이수 학년·학기와 별도 |
| 이름 | 원문 표시 보존, 검색용 공백 정규화. 동명이인을 이름만으로 병합하지 않음 |
| 기준 학년도·출처 | 현재 소속/과거 학적 구분, 입력 파일·문서 구간·판독 상태 |

PDF는 인적·학적사항과 페이지별 학생 식별 구간을 기준으로, XLSX는 명렬/성적 헤더와 병합 셀을 기준으로 구분한다. 이름·학적을 확인할 수 없는 서식은 `학생 정보 확인 필요`로 남기고 로컬에서 보완한다.

학교가 사용하는 학번 규칙이 확인된 경우에만 학년·반·번호에서 학번을 제안한다. 추정한 값은 원문 학번과 구분해 사용자가 확인한다. 이수 당시1학년 성적을 가진 현재2학년 학생을1학년 학생으로 필터링하지 않는다.

### 3.2 화면과 검색 동작

상단 구성:

`학번·이름 검색 [________]  재학 학년 [전체]  반 [전체]  번호 [전체]  초기화`

1. 파일을 가져오면 학생 목록에 `학번 / 학년 / 반 / 번호 / 이름 / 평균 / 확인 필요`를 표시한다.
2. 학번 입력은 정확히 일치한 학생을 우선 표시하고 부분 검색도 지원한다. 이름 입력은 부분 검색하며 동명이인은 소속과 학번으로 구분한다.
3. 학년을 선택하면 해당 반을, 반을 선택하면 해당 번호를 좁힌다. 여러 필터는 AND 조건으로 결합한다. 상위 조건 변경으로 유효하지 않게 된 하위 선택은 해제한다.
4. 결과가 한 명이면 그 학생의 평균과 반영 과목을 바로 표시한다. 여러 명이면 목록에서 한 명을 선택하며 여러 학생의 성적을 한 평균으로 합치지 않는다.
5. 학생을 바꾸면 이름·학번·소속·평균·반영 학점·과목·확인 필요 건수를 같은 학생 기준으로 함께 갱신한다. 해당하지 않는 과거 선택 학생을 남겨두지 않는다.
6. 검색 결과가 없으면 `조건에 맞는 학생이 없습니다`와 초기화를 제공한다. 정보 미확인 학생은 별도 필터로 찾을 수 있다.
7. 학생을 선택한 아래에는 기존 전교과/국영수과사, 성적 이수 학년·학기 필터, 5/9등급 확인을 둔다. 학생 소속 필터와 성적 범위 필터의 이름을 구분한다.

입력할 때마다 서버 조회를 하지 않는다. 학생 목록과 평균은 로컬 데이터·메모이제이션으로 계산하고 대량 목록은 필요한 부분만 렌더링한다.

### 3.3 파일 중복과 기존 저장자료

- 같은 파일 재등록은 내용 해시로 감지한다. 같은 학생의 같은 학년·학기·과목이 중복된 경우 출처를 보여주고 확인하며 임의로 이중 합산하지 않는다.
- 이름만 같은 다른 파일의 학생은 자동 병합하지 않는다. 학년도·확인된 학번·소속·출처를 대조하고 충돌 시 선택을 요구한다.
- 저장 스키마와 판독기 버전을 올린다. 이전 자료는 원본 수정 없이 백업/변환하고, 기존 수동 수정 값을 보존한다.
- 과거 자료에 실제 학번·소속이 없으면 임의로 복원하지 않는다. 보완 또는 원본 재읽기를 안내한다. 재판독에 원본이 필요한 경우에만 사용자가 로컬 원본을 선택한다.
- 원본 PDF·학생 필터·과목 수정·결과·원문 캐시는 산출기 암호화 저장 범위에 넣고 자료 비우기 시 함께 삭제한다. 사용자가 선택한 원본 PDF/XLSX와 다른 기능의 데이터는 보존한다.

## 6. 진행 순서

원인 확인(이번 완료) → 상세계획 저장(이번) → 사용자 다음 지시 후 학생 필터·원문 대조 시안 → 테스트버전에서 판독/검색/자료 이전 검증 → 정식 반영·배포 지시 후 적용. 앱 소스·버전·설치파일·공유 서버는 이번 단계에서 변경하지 않는다.


## 정식 반영 추가 요구 (2026-11-04 승인)

- 사용자 첨부 `(참고) 2022 개정 교육과정 교과목 안내.hwp`의 보통 교과·계열별 선택 과목을 정적 교과 사전으로 반영한다. 한글 원본은 수정하거나 배포하지 않는다.
- 공백·가운뎃점·로마숫자 표기를 정규화한 정확한 과목명으로 연결한다. 한국사1·2는 사회, 정보는 기술·가정/정보에 포함한다. 이름 일부로 추측하지 않는다.
- 원본 교과는 보존하고 화면에 2022 기준/원본/직접 지정 근거를 표시한다. 교과 직접 수정과 기존 수정값을 우선하며, 사전 밖 과목은 원본 교과를 사용한다. 교과 미확인 항목은 국영수과사 계산의 확인 필요에 표시한다.
- 학번은 학년+반2자리+번호2자리(10102) 또는 학년+반1자리+번호2자리(1102)로 해석한다. 4자리는 1~9반만 생성하고 10반 이상은 5자리를 사용한다. 학번 원본을 덮어쓰거나 두 학생을 자동 병합하지 않는다.
