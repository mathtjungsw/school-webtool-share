# 9번 상세계획 · 학교망 연결 복구 후 로그인 다시 확인하기

2026년 11월 18일 · PC 본창 및 위젯 · 전체 항목 검토 후 통합 시험판에서 검증

## 현재 교사가 겪는 문제

PC 앱을 다시 열면 암호화해 저장한 로그인 정보로 학교 서버에 세션의 유효성을 확인한다. 현재 `electron/main/staff-auth.ts`의 복원 처리는 이 요청이 실패하면 공통으로 `clear()`를 호출한다. 학교망이 잠시 끊겼던 교사도 남은 로그인 시간이 있는데 이름과 비밀번호를 다시 입력해야 한다. 또한 현재 로그인 여부는 메모리에 읽은 세션과 만료 시각으로 판단하므로, 서버 응답을 기다리는 상태를 따로 구분해야 한다.

## 교사가 보게 될 화면

| 앱을 열었을 때의 상황 | 화면과 동작 |
| --- | --- |
| 저장된 세션이 있고 서버 확인에 성공 | 본창과 위젯을 원래대로 연다. 비밀번호를 다시 묻지 않는다. |
| 학교망 단절, 응답 시간 초과 등으로 확인 불가 | ‘학교 서버에 연결할 수 없습니다. 연결 상태를 확인한 뒤 다시 시도해 주세요.’와 **연결 다시 확인** 버튼을 표시한다. 저장된 세션을 암호화된 상태로 보존한다. |
| 연결 다시 확인을 누름 | ‘로그인 확인 중…’을 표시한다. 성공하면 바로 열고, 다시 실패하면 같은 화면에서 재시도할 수 있다. |
| 최초 로그인 후 120시간 경과 | ‘로그인 유지 시간이 끝났습니다. 다시 로그인해 주세요.’를 표시하고 이름·비밀번호 입력 화면을 연다. |
| 학교 서버가 세션 취소나 계정 이용 중지를 확인 | 저장된 세션을 정리하고 서버가 확인해 준 사유에 맞게 안내한다. |
| 저장된 세션이 없거나 파일 손상으로 복원 불가 | 일반 로그인 화면을 연다. 복원 실패 시 다시 로그인해야 한다는 이유를 안내한다. |

## 구현 범위

1. PC 메인 프로세스에서 저장된 세션과 서버가 확인한 세션을 구분한다. 확인 대기 중인 세션은 로그인 재확인 요청에만 사용한다. 본창과 위젯은 같은 확인 결과를 사용하고, 버튼을 연속으로 눌러도 진행 중인 요청 하나를 공유한다.
2. 서버 확인 전에는 명렬·개인 시간표·성적 화면, 해당 자료를 반환하는 내부 요청, 개인 일정 알림을 잠근다. 본창보다 위젯이 먼저 열려도 이전 교사의 이름이나 일정이 잠깐 표시되지 않도록 한다. 이미 확인된 로그인에서 일정 조회 한 건이 실패한 경우는 3번 계획의 동기화 실패로 처리한다.
3. 서버가 반환한 세션 무효 응답과 네트워크·프록시·일시적 서버 오류를 구분한다. 중간 장비의 오류 페이지나 형식이 깨진 응답만으로 세션을 지우지 않는다. 특정 메뉴의 권한 거부는 그 메뉴에 적용한다.
4. 만료 기준은 최초 로그인 때 받은 만료 시각이다. 재확인에 성공해도 120시간을 다시 시작하지 않는다. 확인 대기 중에도 만료 시각을 검사한다. 로그아웃하거나 다른 계정으로 전환한 후 도착한 이전 요청의 결과는 폐기한다.
5. 로그아웃은 연결 대기 화면에서도 가능하게 한다. 사용자가 누르면 이 PC의 저장된 로그인 정보를 즉시 지우고 본창과 위젯을 잠근다. 성적 작업 등 교사가 저장한 자료 삭제는 8번 계획의 별도 기능에서 처리한다.

## 통합 시험판 합격 기준

| 시험 상황 | 확인할 결과 |
| --- | --- |
| 가상 교사로 로그인 후 앱 종료 → 네트워크 차단 → 위젯부터 재실행 | 이름·일정·성적과 개인 알림이 노출되지 않고 다시 확인 안내가 뜬다. 다시 실행해도 암호화된 세션이 유지된다. |
| 연결 복구 → 본창과 위젯에서 연속 재시도 | 서버 확인 요청 하나로 양쪽이 열리며 비밀번호를 묻지 않는다. 기존 만료까지 20시간 남았다면 복구 후에도 같은 만료 시각을 사용한다. |
| 시험 시계를 만료 직전과 만료 시각으로 이동 | 경계 시각부터 다시 로그인해야 한다. 연결이 복구되거나 이전 성공 응답이 늦게 와도 열리지 않는다. |
| 취소된 세션 응답, 연결 시간 초과, 프록시 오류 페이지를 각각 입력 | 취소가 확인되면 다시 로그인을 요구한다. 연결 실패와 판독 불가 응답에서는 잠금을 유지하고 재시도할 수 있다. |
| 재시도 중 로그아웃하거나 계정 전환 | 이전 응답이 늦게 도착해도 로그아웃이 풀리거나 다른 교사의 자료가 나타나지 않는다. |

시험에는 가상 계정과 분리된 로컬 프로필을 사용한다. PC 본창과 위젯의 확인 결과를 함께 기록한다.
