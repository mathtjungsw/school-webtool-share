# 웅천고 업무도우미 1.1.36 / 모바일 PWA 1.1.37

- 모바일 시간표의 여백과 행 높이를 줄여 한 화면에서 더 많은 교시를 확인합니다.
- 지난주·이번 주·다음 주 시간표 이동과 실제 날짜, 긴 일정의 상세보기를 제공합니다.
- PC·모바일에서 자료 출처별 확인 시각, 이전 자료 및 조회 실패를 구분합니다.
- 날짜를 한국 시간 기준으로 통일하고 교사 시간표의 시작 날짜를 오늘로 맞춥니다.
- 개인 업무 수정과 위젯 업무·알림의 해당 항목 바로가기를 지원합니다.
- 여러 교시의 일일 예외를 변경 전후 미리보기·겹침 경고와 함께 등록할 수 있습니다.
- A4 자동 축소 후 크기를 다시 검사하고 과도한 축소 대신 여러 장 출력을 안내합니다.

사용자가 제외한 2번(모바일 출결 팝업 갱신 방식), 로그인·보안은 변경하지 않았습니다.
모바일 공개 주소와 기존 자료·세션은 유지합니다. PWA는 APK 대신 기존 주소에서 홈 화면에 설치합니다.
