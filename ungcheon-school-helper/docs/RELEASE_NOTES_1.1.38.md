# 웅천고 업무도우미 1.1.38

교직원 이름과 학교에서 안내한 공통 비밀번호로 로그인합니다. PC 로그인은 **120시간(5일)** 유지되며 만료 후 다시 로그인합니다. 이름만으로 유지하던 이전 PC 로그인은 최초 한 번 재인증합니다. 개인 설정과 기존 작업자료는 보존합니다.

- **업무·학교운영 → 법정의무연수**: 기본으로 이수증 제출 웹앱이 바로 열립니다. 상단의 두 버튼으로 이수증 제출·엑셀 내려받기 웹앱을 전환합니다. 입력 중인 화면을 재사용하며, 새로고침과 기본 브라우저 열기를 제공합니다.
- **진학·대입**: 대학 권장과목을 옮기고 생기부 생성 도우미, 대학 웹진(기본 서울대 아로리), 평균내신등급 산출기, 수시모집 우수사례를 추가합니다.
- **평균내신등급 산출기**: 학생부 PDF·나이스 XLSX DATA를 PC에서 읽습니다. 석차등급이 있는 과목의 `Σ(학점×등급)÷Σ학점`으로 전교과 또는 국어·영어·수학·과학·사회 평균을 계산합니다. 학년·학기·교과·학점·등급을 대조·수정하고 5/9등급 체계를 확인하세요. 나이스 다운로드 안내에 제공된 가림 화면을 함께 넣었습니다. 원본 파일은 변경하지 않으며, 산출기 저장자료 비우기로 이 기능의 로컬 자료만 지울 수 있습니다.
- **수시모집 우수사례**: 일반 로그인 후 추가 비밀번호 `0000`을 입력합니다. 인문·자연 두 권을 개별 등록 없이 중앙에서 받아 대학·학과·전형·결과·키워드로 찾고 PDF 원문을 확인합니다. 자료집은 비공개 보관하며 공개 설치파일·GitHub 소스에 원문이나 색인을 포함하지 않습니다. 최초 열람·개정 시에만 내려받고 PC에 암호화 보관합니다.
- **독서교육**: 웅천 서가와 대학 추천도서를 추가합니다. 추천도서는 목록 후보 100개, 검색·분야·진로 탐색·관심 저장을 제공합니다.
