# 모바일 PWA v1.1.28 긴급 수정 검증

기준일·최종 확인일: 2026-09-09
기준 소스: 최신 `origin/main`의 데스크톱 v1.1.30 및 모바일 PWA v1.1.27 통합본

## 수정 범위

- 창체 일정의 `1·2·3학년` 숫자를 교시로 잘못 읽어 여러 수업·쉬는 시간·점심시간에 반복 표시하던 문제를 수정한다.
- Apps Script가 창체 시트의 교시 열을 `periodStart`, `periodEnd`로 전달한다.
- 모바일은 명시적 교시 필드를 우선 사용하고, 구형 응답은 `○교시`, `○~○교시`, `○·○교시`만 엄격히 해석한다.
- 데스크톱 v1.1.30 코드와 기존 공개 주소·로그인 세션·공통 비밀번호 속성은 변경하지 않는다.

## 회귀 시나리오

- `동아리활동(5교시, 1·2·3학년)`은 5교시에만 표시한다.
- `동아리활동(6교시, 1·3학년)`은 6교시에만 표시한다.
- `학급특색활동(7교시, 1·2학년, 부담임)`은 7교시에만 표시한다.
- `5~6교시, 1·2학년`은 5·6교시에만 표시한다.
- 교시 정보가 없는 창체와 교시 지정 창체 모두 쉬는 시간·점심시간에 잘못 반복되지 않는다.

## 검증 결과

- 모바일 `typecheck`, 전체 단위·통합 테스트 38개, production 빌드 통과.
- 데스크톱 v1.1.30 전체 `typecheck` 및 기존 회귀검사 통과. 데스크톱 설치파일 릴리스는 새로 만들지 않았고 최신 정식판 v1.1.30을 유지함.
- Apps Script 구문·계약 검사, 배포 가드 52개, 모바일 서버 계약 14개 통과.
- 실제 고정 Apps Script 배포를 기존 주소 그대로 project version `@73`, 서비스 버전 44로 갱신함. 배포 절차가 기존 ScriptProperties와 로그인 세션을 초기화하지 않았음을 확인함.
- 모바일 Sites version 11을 기존 공개 주소에 배포함. 공개 응답 HTTP 200, 서비스 워커 HTTP 200, 공개 JS/CSS 6개와 검증 빌드의 해시 일치를 확인함.
- 실제 고정 Apps Script health 응답에서 `UngcheonSchoolHub`, 서비스 버전 44를 확인함.
- 실제 비밀번호·토큰·전체 사용자 응답은 소스·로그·문서에 기록하지 않음. 인증 자료 조회 동작은 합성 교직원 데이터 기반 계약 검사로 검증함.
