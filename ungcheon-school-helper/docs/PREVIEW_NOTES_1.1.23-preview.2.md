# 시험판 1.1.23-preview.2

## 반영 내용

- 생기부 개인정보 블라인드 내장 화면을 밝은 배경과 진한 글자로 전면 교정
- 감사 증빙센터 검색 버튼과 오늘 브리핑 선택 탭의 밝은 모드 대비 개선
- 위젯 행운카드에서 타로·화투 즉시 전환, 카드 닫기, 다시 뽑기 지원
- 인터넷 연결 없이 표시되는 앱 자체 화투 SVG 12개월 그림 추가
- 위젯 `미완료 업무` 버튼에서 개인·배부 업무를 기한순 최대 5건까지 바로 확인
- 위젯 `새 알림` 버튼에서 공지와 수업 변경 알림을 최대 5건까지 바로 확인
- 위젯 요약 패널 열람만으로 완료 또는 읽음 상태가 변경되지 않도록 유지

## 검증

- `npm run typecheck` 통과
- `npm run build` 통과
- Windows NSIS 설치파일 생성 통과
- 밝은 모드 대비, 행운카드 안전 문구, SVG 12개월, 업무·알림 요약 패널 자동검사 통과
