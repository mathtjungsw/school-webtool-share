# v1.1.27 교환·대강 미리보기 정식 업데이트 검증

기준일: 2026-08-31 (Asia/Seoul)

## 반영 범위

- 최신 `origin/main`의 `0bad3b30`(v1.1.26)에서 시작했다.
- 배포 소스 커밋: `169e7eaac9b27b179be450afa033cdab5b2705da`.
- PC 교사 시간표에서 예상 시간표를 교환·대강 후보 교사 목록 바로 위로 이동했다. 하단에는 중복 표시하지 않는다.
- 후보 선택으로 만들어지거나 변경된 미리보기가 화면 밖에 있을 때만 최소 스크롤한다.
- 변경 칸 강조, 연강 안내, 계획서 추가, 닫기, 조건 변경 시 초기화를 유지했다. 검색도우미와 도움말의 위치 설명도 갱신했다.
- 별도 시험판 없이 정식 업데이트를 배포하라는 사용자 요청을 적용했다. 이 항목은 구현·검증이 완료되어 누적 개선 계획에 남기지 않는다.

## 코드·화면 검사

- 데스크톱 전체 `npm run typecheck` 통과.
- 새 미리보기 배치·동작 회귀검사 7개 통과. 이전 하단 배치를 주입하면 실패하는 것도 확인했다.
- 밝은 모드 대비 검사 31개 조합 통과.
- 실제 페이지/계산 코드와 가상 교사 30명을 사용하는 로컬 화면으로 검사했다. 학교 서버·기존 로그인·사용자 자료에 접근하지 않고, 저장은 메모리에서만 처리했다.
- 1280×720: 교환 후보 선택, 목록 끝 후보로 재선택, 미리보기 닫기 확인. 선택된 교사의 미리보기 제목이 화면 상단 약 64px에 표시되었다.
- 900×700: 대강 선택, 밝은 배경과 진한 글자, 변경 전·후 표 표시, 가로 넘침 없음(본문 너비 900px), 계획서 1건 추가와 미리보기 닫힘 확인.
- 화면 검사 중 브라우저 오류 로그 없음. 테스트용 창과 서버는 검사 후 종료했다.
- 데스크톱 `npm run package` 통과. 로컬 Windows 실행파일 제품 버전 1.1.27, GitHub 자동 업데이트 설정 유지.
- 모바일 타입 검사·전체 32개 단위/통합 테스트·프로덕션 빌드 통과.

## 공유 서버·모바일 보존

- Code.gs는 서비스 버전 39→40과 v1.1.27 릴리스 안내만 변경했다. 기존 서버 함수 87개의 본문과 이전 안내 22개는 그대로 보존했다.
- 모바일 계약 검사 14개, Apps Script 배포 가드 52개 통과.
- 최신 main 및 실제 고정 배포/원격 HEAD를 비교하는 `-PreflightOnly` 통과 후 정식 배포 스크립트를 실행했다.
- 기존 고정 Apps Script 배포를 프로젝트 버전 @69, 서비스40으로 업데이트했다. 새 배포 주소를 만들지 않았다.
- 실제 고정 URL health 응답 `ok: true`, `version: 40` 확인.
- 이름·공통 비밀번호, 72시간 세션, 계약3, 출처별 상태, 범위 급식과 todayMeals, 모바일 학생/금지 NEIS 자료 제외 계약을 유지했다.
- ScriptProperties와 로그인 세션은 초기화하지 않았다. 이번 PC 배치 변경에서는 실제 이름/비밀번호 로그인·인증 일정 조회를 다시 실행하지 않았다. 그 부분은 합성 계약 검사와 서버 함수 무변경 비교로 회귀 확인했다.
- 모바일 PWA 소스/배포를 변경하지 않았다. 기존 공개 주소 HTTP200 확인: https://ungcheon-mobile-schedule.jsw890122.chatgpt.site/
