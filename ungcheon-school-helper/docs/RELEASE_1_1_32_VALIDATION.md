## 구현 범위

- 선택 날짜 교사 시간표에 `수업`과 `업무·일정` 2열을 추가하고 1~7교시를 한 줄씩 표시한다.
- 시간 지정 위원회·주간계획·창체·등교/급식지도·개인/공유 업무를 교시 시각과 겹치는 행에 표시한다.
- 여러 교시에 걸친 일정은 시작·진행·종료를 구분하고, 시각만 입력한 일정은 해당 시각의 교시 행에 표시한다.
- 시간이 없는 개인·공유 업무는 `종일 업무` 영역에 표시하며 기존 자료 종류·완료 여부 필터를 따른다.
- 교시로 등록한 공유 업무는 현재 `UNGCHEON_PERIOD_PLAN`을 기준으로 실제 시각을 다시 계산한다.
- v1.1.31의 일일 예외 시간표·교직원 명렬·업무 입력과 기존 모바일 계약을 보존한다.
