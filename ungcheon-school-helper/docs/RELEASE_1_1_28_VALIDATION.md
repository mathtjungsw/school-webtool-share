# v1.1.28 위젯 시간표·일정 통합 검증

기준일: 2026-08-31 (Asia/Seoul)

## 반영 범위

- 최신 origin/main `b9f2edcb1d3bd24fc2c87bcc0e27fcc0c51bc4c3` (v1.1.27)에서 시작했다.
- 사용자의 정식 업데이트 요청에 따라 별도 시험판 없이 구현했다.
- 오늘 시간표 왼쪽은 기존 수업, 오른쪽은 시간 지정 일정으로 구성했다. 시작·종료 시간이 있는 항목은 기간, 시각 하나만 있는 항목은 단일 시각 태그로 표시한다.
- 점심·쉬는시간·수업 전후 일정과 다중 겹침 상세 보기를 지원한다. 일정 상세는 위젯 안에서 읽기 전용으로 확인한다.
- 기존 `오늘 주요 일정` 모듈을 제거했다. 종일·시간 없는 항목은 시간표에서 제외하지만 캘린더·업무센터 원본과 내일 미리보기 자료는 유지한다.
- 위젯 내부 본문 스크롤, 고정 헤더·하단 버튼, 작업영역 내 위치·높이 보정, 핀·투명도 변경 시 높이 보존을 적용했다.
- 기존 일정 표시 설정을 새 통합 설정으로 이전한다. 기존에 시간표를 숨기고 일정만 표시한 경우 통합 시간표를 한 번 표시하며, 이후 사용자의 숨김 선택은 존중한다.
- YYYYMMDD/ISO 날짜 정규화, 위원회 종료 시각 보존, 개인 업무 완료/숨김 설정, 창체 연속·비연속 교시를 검증했다.
- 현재 수업 종료와 다음 수업 시작까지 남은 시간을 구분했다. 12:16 기준 현재 4교시 종료는 14분, 다음 5교시 시작은 74분 후다.
- 검색도우미와 사용 매뉴얼을 갱신했다. 누적 개선 계획의 위젯 두 항목은 구현·검증 완료로 대기 목록에서 비운다.

## 자동·화면 검증

- 데스크톱 전체 typecheck 통과. 새 geometry 10개, 시간 모델·렌더·상호작용 13개, 자료 연결·설정 이전 9개 검사 통과.
- 밝은 모드 대비 39개 조합 통과. 새 일정 색상 8개 조합 포함, 최저 6.11:1.
- 기존 교환·대강, 명렬·출력, 숨김 기능, 운세·행운카드, 업무·알림 관련 회귀 검사를 유지했다.
- 실제 WidgetApp/WidgetTimetable/CSS를 사용하는 합성 자료 화면에서 검증했다. 인증·저장·서버는 메모리 모의 객체이며 실제 교직원·학생 자료나 서버 쓰기를 사용하지 않았다.
- 390×680, 360×400 크기에서 시간표·점심·기간·단일 시각 태그와 고정 하단을 확인했다. 좁은 화면 가로 넘침 0px.
- 360×400에서 헤더 top 약 0.8px, 하단 bottom 약 399.2px. 겹침 상세 3개와 알림을 누르면 본문만 이동하며 헤더·하단은 유지된다.
- 접힘 높이는 약 91px, 접힌 상태 설정은 최소 320px로 확장된다. 설정 스크롤, 시간 지정 일정 전체 끄기, 내 위원회 종류별 끄기·복원, 세부 내용 닫기를 확인했다.
- Windows 배율 100/125/150/200%, 작은/음수 좌표 모니터, 작업표시줄 여백은 순수 geometry 검사로 확인했다. 이 검증은 실제 다중 모니터 기기 시험과 구분한다.
- 최종 Windows package 빌드 통과. app.asar의 버전 1.1.28 및 main/renderer가 최종 빌드와 동일함을 확인했다. GitHub 자동 업데이트 설정을 유지한다.
- 모바일 typecheck, 전체 32개 단위·통합 테스트와 프로덕션 빌드 통과.

- Code.gs를 최신 main과 비교해 서비스40→41과 새 릴리스 안내 추가 이외에는 동일함을 확인했다. 기존 서버 함수 87개와 이전 데스크톱·모바일 안내를 보존한다.

- -ValidateOnly 통과. -PreflightOnly에서 최신 main과 실제 고정 배포 @69, 원격 HEAD 비교 통과.
