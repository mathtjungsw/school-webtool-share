# 시험판 1.1.23-preview.1

제작일: 2026-08-26  
배포 상태: 이 PC 검토용 설치파일만 생성, 정식 자동업데이트 미배포

## 반영 내용

- 감사 증빙센터
  - 규정·기준 검색
  - 감사 예방 사례 검색
  - 로컬 자체점검표와 메모
- 검색도우미 업무 경로 안내 강화
  - 시스템, 담당 역할·부서, 메뉴 경로, 준비사항, 처리 순서, 사후 점검, 자주 하는 실수
  - `도교육청 예시이며, 실제 담당은 학교 업무분장표에 따릅니다.` 안내
- 기준 자료 메타데이터 공통 표시
  - 기준일·적용일, 출처, 최종 확인일
- 공통 인쇄엔진 A4 사전검사
  - 잘림 가능성·예상 쪽수 안내
  - 한 장 문서 자동 축소 선택
- 미니 위젯 오늘의 행운카드
  - 타로·화투 선택
  - 기본 켜짐, 설정에서 끄기 가능
  - 매번 무작위 재추첨, 바로 전 카드 즉시 중복 방지
  - 외부 통신·생년월일 입력 없이 로컬 처리
  - 부정적 예언을 제외한 교직원용 긍정·중립 문구
- 기존 오늘의 운세
  - 교사 이름과 날짜를 기준으로 하루 동안 고정 유지

## 자동검사

- 사이드바·검색도우미 메뉴 일치
- 숨김 미래 기능 노출 방지
- 밝은 화면 글자 대비
- 시간표 변경 허용 작업 목록
- 오늘의 운세 1,000문장 안전성
- 감사 증빙센터·업무 경로·기준자료 메타데이터
- A4 출력 사전검사·자동 맞춤
- 행운카드 27장, 타로·화투, 즉시 중복 방지, 금지 표현
- TypeScript node/web 검사
- Electron production build

## 검토 주의

- 감사 자료는 예방 점검을 위한 참고자료이며 최종 판단은 원문과 최신 공문을 확인합니다.
- 이 시험판은 버전명에 `-preview.`가 포함되어 자동업데이트가 실행되지 않습니다.
