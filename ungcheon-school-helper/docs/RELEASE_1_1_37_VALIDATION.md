# PC v1.1.37 교직원 명렬 순번 고정 검증

기준일: 2026-10-08. 기반: origin/main `859d57a7819ea3f679795814a98fecdb4a1fdf1a`.

## 범위

- 사용자 제공 `26년 전교직원명렬.xlsx` Sheet1의 A5:H38, 순번 1~66 기준. 좌측 1~33 이후 우측 34~66이며 최대식은 전종택으로 정규화한다.
- 데스크톱 명렬 화면·다운로드·연수등록부 초기 명단에서 공유 `displayOrder`를 사용한다. 연수등록부 로컬 편집 후 인쇄는 미리보기 배열을 그대로 사용한다.
- 공유 교원명렬에 displayOrder 열을 추가하고 1회 마이그레이션으로 승인된 66명·직책·순서를 적용한다. 원본은 `교원명렬_20261008_보관`에 보관하며 기존 동일 이름의 ID·부서·교과·담임을 보존한다. 제거 대상의 기록은 보관본에 유지한다.
- 구버전 PC가 순번 없는 명렬을 저장하면 기존 서버 순번을 재사용하여 가나다순으로 돌아가지 않는다. 향후 관리자 Excel 업로드 순번은 저장되며 1회 마이그레이션이 다시 덮어쓰지 않는다.
- 순서 변경 외 시간표·업무·학생 자료·모바일 응답·인증 함수는 변경하지 않는다. 공유 서비스 53→54, PWA 소스/버전/공개 배포는 변경 없음.
- 배포 가드는 리뷰한 정확한 함수/상수 해시만 갱신한다. 빈 명렬 반환·잘못된 기준 이름 변조가 여전히 차단됨을 별도 테스트한다.

- 기존 고정 Apps Script @82 및 원격 HEAD·origin/main 사전 비교 통과. 변경된 service54 소스의 오프라인·온라인 가드 통과.
- `check-staff-roster-order.cjs`: 실제 제공 엑셀의 66개 이름·직책·순번 전체 비교 및 합성 회귀 10그룹 통과. 두 단 순번·최대식 별칭·레거시 자료·추가 직원·보관본·ID/부서/교과/담임 보존·1회 실행·저장/조회·중복 이름 거부·인쇄/다운로드 순서·가드 변조 차단 포함.
