# 업데이트본 배포 방법

웅천고 업무도우미는 공개 GitHub 저장소의 Releases를 이용해 자동 업데이트합니다.
서버 운영비는 들지 않으며, 새 설치본을 Release에 게시하면 기존 프로그램이 시작할 때
새 버전을 확인하고 내려받습니다.

## 관리자 배포 순서

1. 수정한 소스를 GitHub 저장소의 `main` 브랜치에 반영합니다.
2. [GitHub Actions](https://github.com/mathtjungsw/school-webtool-share/actions)로 이동합니다.
3. 왼쪽에서 **웅천고 업무도우미 업데이트 배포**를 선택합니다.
4. **Run workflow**를 누릅니다.
5. 기존 버전보다 높은 버전(예: `1.0.2`)과 변경 내용을 입력하고 실행합니다.
6. 작업이 끝나면 [GitHub Releases](https://github.com/mathtjungsw/school-webtool-share/releases)에
   설치 파일, `latest.yml`, `blockmap`이 함께 게시되었는지 확인합니다.

## 교직원 PC에서의 동작

- 프로그램 시작 시 최신 Release를 자동으로 확인합니다.
- 새 버전이 있으면 백그라운드에서 다운로드합니다.
- 다운로드가 끝나면 **지금 설치**를 눌러 재시작합니다.
- 사용 매뉴얼의 **지금 업데이트 확인** 버튼으로 즉시 확인할 수도 있습니다.
- 개인 설정과 각 기능의 로컬 작업자료는 업데이트 후에도 유지됩니다.

## 배포할 때 지켜야 할 점

- 버전은 반드시 이전보다 높아야 합니다. `1.0.1` 다음은 `1.0.2`처럼 올립니다.
- 한 번 게시한 버전 번호를 다시 사용하지 않습니다.
- Release에서 설치 파일만 올리면 자동 업데이트가 작동하지 않습니다.
  설치 파일과 `.blockmap`, `latest.yml` 세 파일이 모두 필요합니다.
- 현재 설치 파일은 코드 서명이 없어 Windows SmartScreen 경고가 나타날 수 있습니다.
- 저장소가 공개되어 있으므로 Release 설치 파일도 인터넷에서 누구나 내려받을 수 있습니다.
