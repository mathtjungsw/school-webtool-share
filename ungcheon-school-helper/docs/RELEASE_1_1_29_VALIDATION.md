# v1.1.29 위젯 개별 접기·한 줄 시간표 검증

기준일: 2026-08-31 (Asia/Seoul)

## 반영 범위

- 최신 origin/main `b84b911d86e8994879f39b6ba27b9ea448798b84` (v1.1.28)에서 새 정식 배포 작업공간을 만들었다. 이전 작업공간의 다른 변경은 보존했다.
- 배포 소스 커밋: `1f95a0cd56b376abd7d44691152b44d9fd1558e2`.
- 사용자의 정식 배포 요청에 따라 시험판 없이 구현했다.
- 위젯 콘텐츠 12개에 개별 접기·펼치기와 실제 자료 기반 한 줄 요약을 제공한다. 설정의 숨김·순서 및 위젯 전체 접기는 독립적으로 유지한다.
- 설정 schema4의 `moduleCollapsed`를 PC에 저장한다. 이전 버전은 모두 펼침으로 이전하며 기존 표시·일정 종류별 설정을 보존한다. 모듈별 부분 변경은 Electron에서 최신 상태와 합쳐 연속 클릭 시 다른 모듈 상태를 잃지 않는다.
- 접힌 본문은 hidden 속성으로 숨기고 React 자식은 계속 유지한다. 메모·도구 입력이나 뽑은 카드가 기능 접기 때문에 초기화되거나 다시 조회되지 않게 했다.
- 수업·보조행은 26px, 일정 태그는 22px로 압축했다. 수업·일정 상세는 위젯 안에서 확인하며 기간·지정 시각·겹침과 변경 배지를 보존한다.
- 현재 수업 종료와 다음 실제 수업 시작까지 남은 시간을 구분한다. 13:00에 5교시 공강이면 `점심 · 다음 6교시 90분 후`다.
- 접힌 내일 미리보기에 실제 대상 날짜를 포함해 다음 수업일로 넘어갈 때 오해를 막는다.
- 검색도우미와 사용 매뉴얼을 함께 갱신했다.

## 자동 검사

- 데스크톱 전체 typecheck 통과: 기존 교환·대강·출력·숨김 기능·위젯 관련 검사를 유지한다.
- 밝은 모드 글자 대비 48개 조합 통과, 최저 6.11:1.
- 위젯 geometry 10개, 시간표 모델·렌더·상호작용 15개, 자료 연결·이전 9개, 개별 접힘 설정 7개, 공통 접기 SSR·구조 4개 검사 통과.
- SSR 검사는 hidden 본문 구조와 실제 요약·연결된 aria-controls를 검증한다. 실제 입력 상태 유지와 화면 배치는 별도의 브라우저 검증으로 구분한다.
- 모바일 typecheck, 전체 32개 단위·통합 테스트, 프로덕션 빌드 통과. 이번 변경에서 PWA 소스와 공개 주소는 변경하지 않는다.
- Code.gs 오프라인 검사, 모바일 계약 14개 및 배포 가드 52개 통과.
- 읽기 전용 원격 사전 검사에서 최신 main, 고정 배포 @70, 원격 HEAD 비교를 통과했다. 기존 87개 고유 서버 함수는 변경하지 않고 서비스41→42와 v1.1.29 릴리스 안내만 추가한다. 이전 v1.1.24·v1.1.25와 모바일 안내도 유지한다.
- 이번 PC 화면 변경은 실제 이름·비밀번호 로그인 및 인증 일정 조회를 재실행하지 않는다. 해당 부분은 기존 서버 함수 무변경 비교와 합성 계약 검사로 회귀 확인하며, 인증값이나 응답 원문은 기록하지 않는다.

## 합성 화면 검증

- 실제 WidgetApp와 실제 CSS를 메모리 기반 모의 서버·설정으로 렌더링했다. 교직원·학생의 실제 자료나 서버 쓰기를 사용하지 않았다.
- 메모에 입력한 글, QR 도구 입력값, 뽑은 카드가 기능을 접었다 펼쳐도 그대로 유지됨을 확인했다. 기능별 접기 전후 모의 API 호출 수는 11회로 동일했다.
- 표시 중인 11개 기능을 모두 접었을 때 헤더는 각각 24px, 자연 창 높이는 507px로 줄었다. 모든 항목이 한 줄 요약과 펼치기 버튼을 유지했고 하단 버튼은 내용 바로 아래에 있었다. 퇴근 전 브리핑은 기존 표시 시간 전에는 나타나지 않았다.
- 재실행 후 11개 접힘 상태 복원을 확인했다. 모듈 순서를 바꾸고 급식을 숨겼다가 다시 표시해도 급식의 접힘 상태와 나머지 모듈의 상태를 보존했다. 해당 조작으로 모의 API 호출 수는 늘지 않았다.
- 350/360/390px × 100/125/150/200% CSS 배율의 12개 조합에서 본문 가로 넘침 0px, 26px 논리 수업행과 창 안 하단을 확인했다. 별도로 Windows 논리 작업영역·배율·다중 모니터 위치는 geometry 자동 검사로 확인했다. 실제 모니터 배율을 변경한 기기 시험과는 구분한다.
- 360×400px에서 겹침 일정 3개와 알림 상세를 위젯 안에서 열고 닫았다. 본문만 이동하고 헤더·하단이 창 안에 유지됐다.
- 운세 문장과 색·숫자 줄이 옆으로 붙던 이전 CSS 선택자 간섭을 수정했다.
- 최종 소스를 새로 불러와 운세 본문 block·색/숫자 줄 flex 배치와 실제 화면을 다시 확인했다. 16:30에는 퇴근 전 브리핑이 나타나고 별도로 접히는 것도 확인했다.
