# 웅천고 업무도우미 1.1.22

- 바탕화면에서 오늘 시간표·일정·급식·업무·알림을 확인하는 미니 대시보드 위젯을 추가했습니다.
- 위젯은 첫 실행 시 펼친 상태로 시작하며 접기, 항상 위 표시, 투명도와 디자인을 조절할 수 있습니다.
- 현재 수업과 다음 수업을 색과 남은 시간으로 구분하고 교환·대강·당김수업을 함께 반영합니다.
- 위젯 높이를 표시 내용에 맞춰 자동 조절하고 일정·급식·버튼의 간격을 줄여 화면 점유를 낮췄습니다.
- 급식과 오늘의 운세는 개별적으로 숨길 수 있으며, 운세는 외부 전송 없이 PC 안에서만 생성됩니다.
- 검색도우미에 미니 위젯 실행·자동 실행·디자인·운세 관련 안내를 추가했습니다.
