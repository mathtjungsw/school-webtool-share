# 모바일 v1.1.38 특정 요일 시간표 운영 수정

## 범위와 원인

- 최신 origin/main `dac1367ef6726b218a426e3b3c7de9574c96c60e` 기준으로 작업했다.
- PC v1.1.36의 특별 운영일 기준을 모바일이 읽지 않고 실제 날짜의 요일만 사용해, 2026-10-13을 화요일 시간표로 표시했다.
- PC 설치판·교사 주간 시간표 원본·구글시트 내용은 변경하지 않는다.
- 모바일 v1.1.38과 공유 서비스 53만 배포한다. 모바일·Apps Script 기존 고정 주소, 로그인 세션 및 ScriptProperties를 유지한다.

## 변경 내용

- PC의 `specialTimetableDays.ts`를 세 번째 허용 정적 모듈로 동기화하고 해시를 검사한다.
- 8월 11일은 월요일, 10월 13일·11월 9일·11월 17일은 금요일 시간표로 조회한다.
- 날짜별 화면에 운영 안내, 주간 화면에는 실제 날짜·요일과 별도의 운영 요일 표시를 함께 제공한다.
- 일일 예외의 원본 날짜도 운영 요일 기준으로 읽으며 교체·대강·당김수업 적용 순서는 유지한다.
- 서버 출결도 운영 요일 수강생을 사용한다. 출결 자료의 날짜는 대체 원본 요일 날짜가 아닌 실제 수업일이다.
- 서버 운영 요일 목록과 PC 목록의 일치 검사를 추가했다.
- 서비스 워커 앱 셸 캐시를 v13으로 갱신한다. 외부 Apps Script POST는 캐시하지 않는다.
- 기존 데스크톱·모바일 릴리스 안내에 모바일 안내를 추가했으며 삭제·교체하지 않았다.
