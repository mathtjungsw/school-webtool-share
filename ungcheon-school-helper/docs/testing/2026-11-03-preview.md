## 남은 검증·제한

1. 중앙 자료 제공은 현재 PC의 분리 시험 서비스이다. 학교 전체 이용을 위한 비공개 저장소·운영 인증/자료 서버 배포·모바일의 실제 전환 검증은 다음 배포 단계이다.
2. 도서 원목록·판본·전권 해설/진로 연결 출처 검토는 미완료이다. 자동 생성 해설을 검토 완료로 표시하지 않았다.
3. PDF 성적의 학년/학기·학생 표시명·서식별 누락, 우수사례 지원 행·구획·마지막 쪽의 전수 원문 대조, 서로 다른 입력 파일 간 동일 학생 병합은 추가 작업이 필요하다. 원문 대조 전에는 확정 자료로 사용하지 않는다.
4. 실제 유료 AI 기능·Google 계정 로그인·웹진 10곳 전체 이북/링크는 검증하지 않았다. 한양대 HYPER/ERICA 직접 진입 세분화도 추가 대조 대상이다.
5. 실제 두 설치 버전의 업데이트·미저장 작업 자동 수집·장시간 재안내·Windows 알림 제한·삭제 잠금 실패/중단 복구 등 계획 검증표 전체를 통과한 상태는 아니다. 시험 알림과 정상 경로 중심의 초기 실행본이다.

초기 테스트 실행본의 제공과 아홉 항목의 전체 완료 판정을 구분한다. 정식 반영 전에는 위 제한과 상세계획의 AG/SC/AU/UP 미확인 항목을 해결하고 결과를 갱신한다.
