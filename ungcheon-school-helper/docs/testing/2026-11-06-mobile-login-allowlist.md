# 추가 허용 이름의 모바일 일정 로그인 (2026-11-06)

사용자가 PC 로그인에 추가한 같은 이름으로 모바일 일정도 이용하도록 요청했다. 교직원 명렬에 추가하지 않는 조건을 유지한다.

- 기존 추가 로그인 이름 해시 목록을 모바일 이름 검증에서도 확인한다. 공통 비밀번호 검증·72시간 모바일 세션·요청 사용자와 토큰 일치 확인을 유지한다.
- 실제 교직원 명렬·교사 시간표·교원 정보·출력 명단은 수정하지 않는다. 개인 시간표가 없는 경우 다른 교사의 시간표를 대신 표시하지 않는다.
- 추가 합성 검증: 비명렬 이름의 모바일 로그인/72시간 세션·일정 계약3·개인 시간표 없음·명렬 불변, 잘못된 비밀번호/다른 이름 토큰 거부, 허용 취소 시 접근 거부, 기존 명렬 사용자 세션 유지.
- 필수 typecheck 통과. 모바일 계약24개·배포 가드56개 통과. 클라이언트 변경 없이 고정 공유 서버만 서비스60으로 갱신한다.

실제 모바일 로그인·일정 조회 및 명렬 대조 결과는 적용 후 기록한다.
