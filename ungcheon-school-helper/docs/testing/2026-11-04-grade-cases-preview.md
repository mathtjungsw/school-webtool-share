## 변경 내용

1. PDF.js의 텍스트 좌표와 표 선을 함께 읽는다. 과목 셀의 여러 글줄을 결합하고 학점·석차등급을 같은 행에 연결한다. 학기·교과 병합 범위를 처리하며 누락·무등급·확인 필요 상태를 구분한다.
2. 학생별 이름·재학 학년·반·번호와 성적의 이수 학년/학기를 분리한다. 학번·이름 검색과 학년/반/번호 AND 필터, 학생별 평균 목록과 상세를 제공한다. 학번이 없는 원문은 자동 확정하지 않으며 사용자가 학교의 1자리학년+2자리반+2자리번호 규칙을 확인해 설정하거나 직접 수정할 수 있다.
3. 동일 파일의 내용 해시로 중복 등록을 차단한다. 수동 수정과 확인 상태를 암호화 보관하며 PDF 원문 행을 강조해 대조한다. 자료 비우기는 학생·성적·원문 캐시·이전 자료 백업을 함께 지우고 선택했던 원본 파일은 유지한다.
4. 우수사례는 잠금 해제 후 인문 자료집 표지 PDF를 기본으로 연다. 마지막 권/쪽 복원, 사례 시작 쪽 이동, 페이지 이동·확대·너비 맞춤, PDF/정리 보기 전환을 지원한다.
5. 지원현황 표는 내신이 빈 행도 읽고, 본문을 표·항목 제목·문단으로 나눈다. 모든 구조화 결과에는 원문 대조 상태를 유지한다. 실제 원문에 없는 내용을 AI로 생성하지 않는다.
6. 기존 원문 바이트가 있는 사례 캐시는 새 파서로 로컬 재판독한다. 원문 개정과 파서 버전을 분리해 새 구조를 위해 같은 PDF를 중앙에서 다시 받지 않는다.

## 시험 범위와 남은 제한

- 이번 예시 PDF의 성적 행과 주요 수치를 대조했다. 다른 모든 학생부 PDF 서식의 정확도나 손상·회전·스캔·암호화 PDF 지원을 보장하지 않는다. 로컬 OCR 자동 판독은 이번 실행본에 추가하지 않았다. 글자층을 읽지 못하면 나이스 DATA 입력을 안내한다.
- 기존 v1.1.38의 학번 없는 저장자료는 임의로 신원을 생성하지 않는다. 확인 필요로 복원하고 원본 재등록/학생 정보 보완을 안내한다. 기존 수동 값은 유지한다.
- 다른 입력 파일에서 같은 이름을 가진 학생은 자동으로 합치지 않는다. 동일 파일 재등록은 내용 해시로 배제한다.
- 사례의 지원 표·복잡한 병합 표·본문 구획은 원문과 대조해야 한다. 두 권 모든 셀을 수동 검수한 것으로 보고하지 않는다. 제목·표·문단을 정리하되 구조 불확실 표시를 유지한다.
- 시험 앱은 이 PC의 별도 loopback 인증/자료 서비스를 사용한다. 관리자 설정·자료 경로는 설치본 밖에 있다. 다른 PC에서의 중앙 운영 서버 전환은 이번 범위가 아니다.
- 최종 패키징된 실행파일의 기능을 검증했다. NSIS 설치 마법사를 거친 설치·제거 전 과정을 이번 검사에서 실행한 것은 아니다.
- 실제 학생 성적·사례 본문 화면을 결과 폴더에 저장하지 않는다. 공개 확인 화면은 합성 학생/빈 산출기/잠금 화면만 사용한다.
