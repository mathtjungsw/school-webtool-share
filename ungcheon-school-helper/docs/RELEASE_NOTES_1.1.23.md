# 웅천고 업무도우미 1.1.23

## 주요 개선

- 바탕화면 위젯의 `새 알림` 숫자와 펼친 목록이 같은 기준을 사용하도록 수정했습니다.
- 이미 취소·승인·보류되어 끝난 수업 변경과 날짜가 지난 요청은 새 알림에서 제외했습니다.
- 위젯 `오늘 주요 일정`에 개인 일정, 개인 업무, NEIS 학사일정, 내 위원회, 주간업무계획, 등교지도, 급식지도, 창체 일정을 표시합니다.
- 위 8가지 일정은 위젯 설정에서 각각 켜고 끌 수 있습니다.
- 위젯 일정 체크박스는 대시보드 달력 체크박스와 별도로 저장됩니다.
- 당김수업과 수업 교체·대강 변경사항은 주요 일정에 중복 표시하지 않고 오늘 시간표에만 반영합니다.
- 생기부 개인정보 블라인드, 감사 증빙센터, 오늘 브리핑의 밝은 화면 대비를 개선했습니다.
- 행운카드에 타로·화투 전환, 카드 닫기, 앱 자체 화투 SVG 12개월 그림을 추가했습니다.
- 위젯 안에서 미완료 업무와 새 알림을 최대 5건까지 바로 확인할 수 있습니다.

## 검증

- 밝은 모드 대비 검사 통과
- 위젯 일정 독립 필터와 새 알림 필터 회귀검사 통과
- TypeScript 타입검사 및 Windows 설치파일 빌드 검사 통과
