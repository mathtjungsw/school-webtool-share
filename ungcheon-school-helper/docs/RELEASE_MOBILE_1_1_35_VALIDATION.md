## 반영 내용

- 3학년 수업은 이동수업·학급수업 구분 없이 실제 수강생 기준 출결을 연결한다.
- 공동교사 표기와 줄어든 교사명은 실제 교사시간표의 같은 교시·과목·교실을 함께 대조한다.
- 같은 교시에 담당 교사명이 포함되어도 과목이 다른 학생은 출결 대상에서 제외한다.
- 3학년 수업인데 연결 결과가 없으면 버튼 영역을 숨기지 않고 `연결 확인` 상태를 표시한다.
- 새로고침 중 경과 초를 표시하고, 서비스 워커가 새 앱 코드로 교체되면 열린 PWA를 한 번 갱신한다.
- Apps Script POST와 외부 요청은 서비스 워커가 가로채거나 캐시하지 않는다.
