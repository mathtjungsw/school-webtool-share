# 웅천고 업무도우미 v1.1.35

- 교장·교감 계정도 일반 교사와 동일하게 이름 로그인과 72시간 기본 세션을 사용하므로, 프로그램을 다시 실행해도 바탕화면 위젯이 같은 사용자로 자동 연결됩니다.
- `교장메뉴`·`교감메뉴`는 기본 로그인과 분리해, 해당 보호 메뉴를 처음 열 때만 추가 비밀번호를 확인합니다.
- 보호 메뉴의 역할·접근 토큰·추가 비밀번호는 위젯에 전달하거나 저장하지 않습니다.
- 보호 메뉴 인증이 만료되더라도 프로그램 전체를 로그아웃하지 않고 보호 메뉴만 다시 잠급니다.
- 보호 메뉴를 닫았다가 다시 열 때 이전 오류 문구나 입력한 비밀번호가 남지 않도록 정리했습니다.
