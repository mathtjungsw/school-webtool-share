## 승인 범위

사용자는 추천 2번을 제외하고 모두 수정하도록 요청했다.
모바일은 스크롤을 줄여 많은 교시를 보는 방향이며, PC의 우선 메뉴는 교사 시간표·대시보드·학생 위치 찾기다.
2번 모바일 출결 팝업의 요약/전체 명렬 갱신 방식, 보안 및 로그인은 변경하지 않았다.

## 반영 내용

1. 날짜: 새 업무·문서 날짜 등 UTC 날짜 잘라내기를 한국 시간 날짜 공용 함수로 대체. 교사 월별 시간표의 고정 초기 날짜를 오늘 기준으로 수정.
3. 자료 상태: 모바일 시간표 상태는 기본 시간표·수업 변경·일일 예외를 함께 확인하며, 관련 출처 중 가장 오래된 정상 확인 시각을 표시. PC는 확인/수신 시각과 최근 실패를 구분하고 캐시된 동기화 목록 확인을 새 조회처럼 표시하지 않는다.
4. 모바일 밀도: 상단 안내·현재/다음 요약을 접어두고 날짜 선택 및 교시 행 압축. 320px 폭의 가로 넘침 제거. 내용과 출결 버튼은 삭제하지 않음.
5. 인쇄: 실제 A4 물리 크기를 기준으로 검사, 자동 축소 후 재검사. 55% 미만 축소가 필요한 경우 자동 맞춤을 제안하지 않고 여러 장 출력 선택을 제공.
6. 주간 시간표: 지난주/이번 주/다음 주 및 각 요일의 실제 날짜 표시. 조회 범위 21일로 기존 최대 22일 계약 이내.
7. 위젯 바로가기: 업무는 업무센터 해당 항목·탭을 열고, 공지는 해당 공지, 수업 변경은 처리 내역을 표시/강조.
8. 개인 업무: 연필 버튼으로 제목·날짜·시간·우선순위·메모 수정. 기존 ID·등록일·완료 상태 보존. 저장 실패 시 입력 유지, 저장 중 중복 입력 방지. 좁은 PC 화면에서 입력폼이 목록 버튼을 덮지 않도록 고정 위치 적용을 넓은 화면으로 제한.
9. 일일 예외: 복수 교시의 원본 교시/비우기/당김 이동 일괄 선택. 실제 공통 시간표 계산으로 적용일과 당김 원본일의 교사별 변경 전후 비교. 전 학년·학년·반의 포함 관계 및 당김 원본 중복 경고. 저장 직전 공유 자료 변경 여부 재확인.
10. 긴 일정: 제목을 누르면 전체 제목, 날짜, 시간, 장소, 출처를 표시. Escape·닫기·배경 클릭으로 종료.

검색도우미의 이용 순서와 검색어도 갱신했다. 기존 릴리스 안내·공개 URL·비밀번호 속성·로그인 세션·Apps Script Code.gs는 변경하지 않았다.

## 로컬 화면 확인

실제 교직원·학생 자료나 운영 시트 쓰기 없이 합성 자료만 사용했다.

- 모바일 390×844: 수업 전 일정·점심·출결 연결 표시·시간 지정 일정을 포함한 샘플에서 1~7교시가 첫 화면에 표시됨.
- 모바일 320×740: 문서 가로 폭 305px, viewport 320px로 가로 넘침 없음. 샘플 7교시 하단 약 734px. 일정/출결 내용이 많거나 글자 확대 시 필요한 세로 스크롤은 유지.
- 주간 시간표 지난주 이동, 실제 날짜, 경계에서 이동 버튼 비활성화 확인.
- 긴 위원회 일정 상세의 전체 제목·시간·회의실·출처 및 닫기 확인.
- PC 개인 업무의 제목/메모 수정 후 동일 ID·등록일·완료 상태 유지 확인.
- 복수 교시 변경 미리보기 및 두 번째 저장을 인위적으로 실패시킨 검사: 첫 교시 저장분은 유지, 남은 교시만 재미리보기/저장, 중복 없음.
- 긴 90행 인쇄물: 예상 3쪽 표시, 과도한 자동 축소 버튼 미표시, 여러 장 출력 제공. 실제 프린터 출력은 실행하지 않음.

## 배포 전 주의

- 여러 교시 저장은 기존 API를 사용하는 순차 저장이지 서버 트랜잭션이 아니다. 중간 실패 시 완료분을 유지하고 남은 선택만 재시도한다. 다른 관리자가 동시에 수정할 가능성이 있는 경우 함께 작업하지 않도록 안내한다.
- 실제 Electron 설치본의 창 간 이동, 실제 시트 저장, 실제 iPhone 및 프린터 출력은 배포 전 별도 확인 대상이다.
- 이번에는 코드·로컬 번들만 검증했다. 버전 증가, 설치파일 제작, commit/push, GitHub Release, Apps Script 및 PWA 공개 배포는 수행하지 않았다.
