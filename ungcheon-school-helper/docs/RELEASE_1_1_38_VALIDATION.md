## 정식 전환

공식 appId·제품명·설치파일 이름을 기준 main에서 복원한다. 정식판은 기존 고정 Apps Script를 사용하며 시험 loopback 서비스와 시험 계정 설정을 사용하지 않는다. 기존 모바일 공통 비밀번호 검증값을 PC에서도 재사용하므로 비밀번호 초기 설정·변경이나 모바일 활성 세션 초기화가 필요하지 않다. PC에서 새로 발급하는 세션만 120시간이며 기존 모바일 세션 계약은 보존한다.

우수사례는 추가 Sheets API 활성화·Apps Script Drive 권한 확장을 요구하지 않는 비공개 Drive 문서에 원문 바이트를 분할 보관한다. 원문과 중앙 저장물의 SHA256을 왕복 확인했다. 보관소에는 소유자 권한만 있고 공개 링크를 만들지 않는다. 서버의 SpreadsheetApp 권한으로 요청한 한 권만 읽고 원문 무결성을 확인한다. 클라이언트에는 저장소 포인터를 반환하지 않는다. 포인터 자체는 접근 권한이 아니며 공개 소스의 서버 설정과 실제 자료의 공유 권한을 구분한다.

설치본은 비공개 초안으로 준비한 뒤 기존 고정 서버 전환·인증된 실제 조회·미인증 거부를 확인하고 정식 최신 Release로 공개한다. 새 Apps Script 배포 ID는 만들지 않는다. GitHub main과 Apps Script 고정 배포·HEAD의 동시 변경을 배포 가드로 확인한다.
