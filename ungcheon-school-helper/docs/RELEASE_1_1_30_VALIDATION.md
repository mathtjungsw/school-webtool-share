# v1.1.30 시간 지정 일정·위젯 순서·모바일 시간표 통합 검증

기준일·최종 확인일: 2026-09-05 (Asia/Seoul)

## 반영 범위

- 최신 `origin/main`의 v1.1.29 통합 소스를 기준으로 정식판을 개발했다. 과거 분리 작업본을 재사용하지 않았다.
- 위젯의 각 기능 제목에 이동 손잡이를 추가했다. 표시 중인 기능을 끌어 순서를 바꾸면 전체 모듈 순서에 반영되고, 환경설정과 같은 로컬 설정에 저장된다.
- 7교시를 15:40~16:30으로 보정했다. 이전 기본값 15:30을 사용하던 PC는 최초 실행 때 새 시각으로 한 번만 이전하며, 이후 사용자가 직접 바꾼 값은 유지한다.
- 현재 운영 교직원 명렬·교사 시간표·당김수업 자료의 `최대식`을 `전종택`으로 변경했다. 서버는 기존 시트의 현재 명렬과 시간표 행을 한 번만 이전하고 감사용 과거 이력이나 로그인 세션은 초기화하지 않는다.
- 개인 일정·개인 업무와 공유 업무에 시작 시각 및 선택적인 종료 시각을 추가했다. 시작 시각만 있으면 지정 시각 태그, 종료 시각까지 있으면 시간 범위와 종료 시각으로 표시한다. 공유 업무의 실제 진행 날짜·시각은 시작일·마감일과 별도로 저장한다.
- 모바일 일정 PWA의 오늘/선택 날짜 시간표를 왼쪽 수업, 오른쪽 시간 지정 일정으로 나눴다. 수업 교환·대강·당김수업은 수업 칸에만 반영해 일정 칸에 중복하지 않는다. 수업 없는 날은 가짜 공강 7칸을 만들지 않는다.
- 모바일 급식은 조식·중식·석식 순으로 표시한다. 기존 72시간 로그인, `contractVersion: 3`, 출처별 `sourceStatus`, 요청 범위 급식과 `todayMeals`, 학생 자료 제외, NEIS 직접 호출 금지 및 고정 공개 주소를 유지한다.
- Apps Script 공유 서비스는 서비스43으로 올리고, 기존 고정 배포만 갱신하도록 배포 가드를 강화했다. v1.1.24·v1.1.25를 포함한 기존 데스크톱·모바일 릴리스 안내를 보존했다.

## 자동 검사와 패키징

- 데스크톱 전체 typecheck 통과. 밝은 모드 대비, 기존 교환·대강·학생 위치·출력·숨김 기능 및 위젯 회귀 검사를 모두 유지했다.
- 위젯 시간표 모델·렌더 검사 15개, 일정 연결 검사 9개, 접힘 설정 검사 7개, 공통 접기 구조 검사 4개, 창 크기 검사 10개 통과.
- 모바일 typecheck, 단위·통합 테스트 36개, 프로덕션 빌드 통과. 공유 정적 시간표 자료는 데스크톱 v1.1.30 해시와 일치한다.
- Apps Script 구문·모바일 계약 14개·배포 가드 52개 통과. 합성 검사에서는 비밀번호·토큰·실제 교직원 또는 학생 자료를 사용하지 않았다.
- Windows 패키징 통과. 설치본 내부 `package.json` 버전은 1.1.30이며 `latest.yml`도 같은 설치파일명과 버전을 가리킨다.
- 로컬 설치파일 `UngcheonSchoolHelper-Setup-1.1.30.exe`: 184,046,587바이트. 로컬과 CI는 빌드 환경이 달라 공식 자산의 크기·해시가 달라질 수 있다.
