# 아이디어 노트

이 문서는 개선계획으로 확정하기 전에 조금 더 고민해 볼 아이디어를 별도로 보관합니다.

## 운영 원칙

- 개선계획의 앞 단계가 아니라, 개선계획과 나란히 운영하는 독립적인 메모 공간입니다.
- 사용자가 **“아이디어 노트에 넣어줘”라고 명시한 내용만** 기록합니다.
- 일반 질문, 제안, 개선의견을 임의로 이 문서에 추가하지 않습니다.
- 기록된 아이디어는 검토 후 개선계획으로 옮길 수도 있고, 보류하거나 폐기할 수도 있습니다.
- 아이디어를 개선계획으로 옮길 때는 사용자의 명시적인 요청을 따릅니다.
- 이 문서를 수정하는 것만으로 앱 코드·버전·설치파일·배포 상태를 변경하지 않습니다.

## 검토 중인 아이디어

### 데스크톱 미니 대시보드 위젯

#### 아이디어 개요

- 웅천고 업무도우미의 핵심 정보를 작은 반투명 위젯으로 화면 한쪽에 항상 표시한다.
- 위젯의 `프로그램 열기` 버튼을 누르면 기존 업무도우미 전체 화면이 열린다.
- 대시보드 전체를 축소하지 않고, 자주 확인하는 정보만 간결하게 보여주는 별도의 미니 대시보드로 구성한다.

#### 현재 검토 중인 표시 항목

- 오늘 시간표 전체(1~7교시)
- 현재 수업 강조 표시
- 다음 수업 강조 표시 및 수업까지 남은 시간
- 오늘 주요 일정
- 오늘 급식
- 미완료 업무 개수
- 알림 개수
- 프로그램 열기
- 위젯 접기
- 위젯 위치 고정·고정 해제
- 투명도 조절

#### 사용 방식 초안

- 화면 오른쪽 상단 등 사용자가 정한 위치에 배치하고 마지막 위치를 기억한다.
- 기본 투명도를 적용하고 마우스를 올리면 선명하게 표시하는 방식을 검토한다.
- 오늘 시간표는 모든 교시를 한눈에 확인할 수 있게 표시한다.
- 현재 수업은 눈에 띄는 배경색과 굵은 테두리로 구분한다.
- 다음 수업은 현재 수업과 다른 계열의 색·테두리로 구분하고, `다음 수업까지 18분`처럼 남은 시간을 함께 표시한다.
- 공강은 수업 칸보다 약한 색으로 표시해 수업과 빠르게 구별한다.
- 교체·대강·당김수업 등 평소와 다른 수업은 별도의 변경 배지나 강조색을 사용한다.
- 항상 위 표시 여부를 사용자가 선택할 수 있게 한다.
- 접으면 학교 로고나 작은 막대만 남기고, 클릭하면 다시 펼친다.
- 컴퓨터 시작 시 위젯 자동 실행 여부를 선택할 수 있게 한다.
- 위젯 자동 실행은 기본값을 `켜짐`으로 설정해, 사용자가 별도로 기능을 찾지 않아도 처음부터 위젯을 발견할 수 있게 한다.
- 위젯 안에 `Windows 시작 시 자동 실행` 체크박스를 표시하고 기본적으로 체크해 둔다. 사용자는 체크를 해제해 이후 자동 실행을 끌 수 있다.
- 부정형인 `자동 실행 끄기` 체크박스는 현재 상태를 혼동할 수 있으므로 사용하지 않는다.
- 첫 실행 시 `PC를 켜면 미니 위젯도 자동으로 시작됩니다`라는 짧은 안내를 표시하고, 이후에는 위젯 설정이나 트레이 메뉴에서 같은 옵션을 변경할 수 있게 한다.
- 바탕화면의 밝기와 색상에 맞춰 선택할 수 있도록 여러 개의 위젯 디자인 프리셋을 제공한다.
- 디자인 선택 화면에는 각 프리셋의 실제 미리보기를 보여주고, 선택 즉시 현재 위젯에 반영한다.
- 위젯 디자인은 메인 프로그램의 화면 모드와 분리해 관리하되, 모든 프리셋은 충분한 글자 대비를 유지한다.
- 검토할 기본 프리셋은 `밝은 유리`, `불투명 흰색`, `어두운 유리`, `웅천고 노랑`, `초간단 한 줄형`이다.
- 프리셋별로 배경·글자·테두리 색을 안전하게 묶어 제공하고, 투명도는 프리셋 선택 후 별도로 미세 조절할 수 있게 한다.
- 사용자 임의 색상 조합은 글자가 보이지 않는 문제를 만들 수 있으므로 초기 버전에서는 제공하지 않고, 검증된 프리셋 선택 방식부터 적용하는 방안을 검토한다.
- 여러 모니터 사용 시 마지막으로 놓은 모니터와 위치를 기억하는 방안을 검토한다.
- 상세 일정이나 개인정보는 위젯에 과도하게 노출하지 않고, 클릭 후 프로그램에서 확인하게 한다.
