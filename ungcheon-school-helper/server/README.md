# 학교 공유 서비스 설정

공지, 부서별 공유 링크, 기능개선 요청, 교사·학생 시간표, 교원·학생 명렬과 업무 체크리스트를 모든 교직원에게 동기화하기 위한 무료 Google Apps Script 구성입니다.

1. 학교 Google 계정으로 새 Google 스프레드시트를 만듭니다.
2. `확장 프로그램 → Apps Script`를 엽니다.
3. 기본 코드를 지우고 `Code.gs` 내용을 붙여 넣습니다.
4. `initialSetup()`의 `CHANGE_ME`를 관리자 비밀번호로 잠시 변경합니다.
5. `initialSetup` 함수를 한 번 실행하고 권한을 승인합니다.
6. 코드의 비밀번호를 다시 `CHANGE_ME`로 바꾸고 저장합니다.
7. `배포 → 새 배포 → 웹 앱`을 선택합니다.
8. 실행 사용자는 `나`, 접근 권한은 학교 정책에 맞게 설정합니다.
9. 생성된 `/exec` URL을 업무도우미의 `환경설정 → 학교 공유 서비스`에 입력합니다.

관리자 비밀번호 원문은 스프레드시트나 프로그램에 저장하지 않으며, Apps Script 속성에 SHA-256 값으로 저장됩니다.

코드를 업데이트한 뒤에는 Apps Script에서 `배포 → 배포 관리 → 수정 → 새 버전`을 선택해야
기존 웹 앱 URL에 변경 사항이 반영됩니다. 서버 버전 6이 실행되면 기존 시간표 시트에 더해
`교원명렬`, `학생명렬`, `업무체크리스트`, `업무체크응답` 관련 시트가 자동 생성됩니다.

시간표 업로드는 업무도우미의 관리자 모드에서만 가능합니다. `주간시간표` 시트가 있는
XLSM·XLSX·XLS 파일을 선택하면 파일을 PC에서 분석한 뒤 시간표 내용과 교체 제한 표시만 저장하며,
기존 시간표는 새 시간표로 전체 교체됩니다. Excel 원본과 VBA 코드는 서버로 전송하지 않습니다.

프로그램은 항상 사용자 모드로 시작합니다. 관리자 모드는 서버에서 비밀번호를 확인한 현재 실행 중에만
유지되며, 앱을 종료하면 자동으로 해제됩니다.

학생별 시간표 업로드도 관리자 모드에서만 가능합니다. 전체시간표·강좌·수강생 Excel 파일은
관리자 PC에서 분석되며, 서버에는 학생별 조회·인쇄에 필요한 학번, 이름, 수업 내용만 저장됩니다.
Excel 원본과 원본 다운로드 기능은 제공하지 않습니다. 일반 사용자는 공유된 결과를 읽고 인쇄만 할 수 있습니다.

교원 명렬과 학생 명렬도 관리자 PC에서 Excel을 분석한 뒤 조회·출력에 필요한 값만 저장합니다.
업무 체크리스트는 로그인 도입 전까지 환경설정의 교사 이름을 작성자·응답자 확인 기준으로 사용하므로,
공식 결재나 법적 출석 확인이 아닌 내부 업무 진행 확인 용도로 사용합니다.

`RELEASE_NOTES`에 새 버전의 제목·변경 내용·날짜를 추가하면 서버 배포 후 공지사항에 한 번만
자동 등록됩니다. 업데이트할 때마다 새 항목을 누적하고 기존 항목은 삭제하지 않습니다.

공유 시트에는 교원 명렬·업무 응답, 교사 시간표와 학생 이름·학번·수강 정보가 저장되므로 학교 계정과 학교 정책에 맞는
접근 권한으로 배포하세요. 성적, 연락처 등 시간표 조회에 불필요한 개인정보는 저장하지 않습니다.
