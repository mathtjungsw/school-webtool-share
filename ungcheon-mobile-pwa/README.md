# 웅천고 모바일 일정 PWA

PC용 `ungcheon-school-helper`와 같은 최신 main에서 관리하는 교직원용 읽기 전용 모바일 앱입니다. 개인 업무·개인 일정·학생 자료·검색도우미·승인 및 편집 기능은 포함하지 않습니다.

공개 주소는 **https://ungcheon-mobile-schedule.jsw890122.chatgpt.site** 이며 기존 Sites 프로젝트와 Apps Script 고정 주소를 그대로 사용합니다. 데스크톱 v1.1.30 / 모바일 1.1.27 / 공유 서비스 43 통합본입니다.

## 재사용하는 조회 계약

Apps Script의 읽기 전용 모바일 조회 액션만 사용합니다.

| 액션 | 사용 데이터 | 모바일 처리 |
| --- | --- | --- |
| `verifyMobileViewer` | 교직원 이름과 기존 공통 비밀번호 | 이름 일치·비밀번호 확인 후 72시간 세션 발급 |
| `getMobileScheduleBundle` | 로그인 교사의 시간표·위원회·수업 변경, 주간계획·창체·창체 학사일정·등교/급식지도와 관리자 PC가 미리 공유한 요청 기간 급식 | 모바일 전용 최소 조회 중계. 날짜별 급식을 제공하되 서버에서 명렬 일치 재검증. 모바일은 NEIS API를 직접 호출하지 않음 |

응답은 기존 자료 필드와 함께 출처별 `sourceStatus`를 제공합니다. 한 출처가 일시적으로 실패하면 다른 자료는 최신본으로 갱신하고, 실패한 부분만 사용자별 IndexedDB의 마지막 정상본으로 보완합니다. 정상적으로 0건인 자료와 조회 실패를 구분합니다.

모바일이 호출하는 액션은 위의 두 가지뿐입니다. 교사 시간표·위원회·수업 변경은 서버가 로그인 교사 범위로 선별하여 묶음에 포함하며 개별 데스크톱 조회 API를 호출하지 않습니다.

당김수업과 교시 시각은 최신 데스크톱 자료를 `npm run sync:shared`로 `src/shared`에 동기화합니다. 허용된 두 정적 파일만 복사하고 빌드·타입검사 전 해시를 비교합니다. 독립 Sites 소스에서도 상위 폴더 없이 재현할 수 있습니다.

## 보안·캐시 원칙

- 이름 완전 일치와 학교 공통 비밀번호를 함께 확인하며 72시간 후 자동 만료됩니다. 기존 ScriptProperty와 유효 세션은 배포로 초기화하지 않습니다.
- API 요청은 읽기 전용 조회 액션으로 제한하고, 앱에 생성·수정·삭제·승인 코드를 넣지 않습니다.
- 사용자별 정상 조회 스냅샷은 이름의 SHA-256 키로 IndexedDB에 저장합니다. 서비스 워커는 동일 출처 앱 셸만 캐시하며 Apps Script 응답은 캐시하지 않습니다.
- 로그아웃하면 세션 이름과 해당 사용자의 IndexedDB 스냅샷을 삭제합니다.
- API 조회 제한은 35초입니다. 세션 만료는 네트워크 실패와 구분하고 `로그인이 만료되었습니다. 다시 로그인해 주세요.` 안내 후 로그인 화면으로 이동합니다.
- IndexedDB 조회는 API와 병렬이며 저장 실패가 정상 응답을 연결 실패로 바꾸지 않습니다. 저장소가 막혀도 제한 시간 후 조회를 계속하고 최신 자료는 메모리에 표시합니다.
- 앱 복귀·네트워크 복구·한국 시간 날짜 변경 시 자동 갱신합니다. 같은 범위의 진행 중 요청은 공유하고, pageshow/visibilitychange/online 연속 이벤트는 1.5초 안에 합칩니다. 실제 사용자·날짜 범위 변경이나 로그아웃 때만 오래된 요청을 취소합니다.
- 마지막 정상 조회와 비교해 새로 추가되거나 내용이 바뀐 일정만 `NEW`로 표시합니다. 배열 정렬 순서는 변경으로 취급하지 않습니다.
- 모바일 앱은 NEIS 스냅샷이나 NEIS 학사일정을 요청·전송·캐시하지 않습니다.
- 모바일 전용 조회 액션은 로그인한 교직원에게 필요한 자료만 응답하며, 다른 교직원의 명렬·위원회·시간표를 브라우저로 보내지 않습니다.
- Apps Script는 `ungcheon-school-helper`에서 `npm run deploy:apps-script`로 기존 고정 배포만 갱신합니다. 최신 main·실제 고정 버전·원격 HEAD의 데스크톱/모바일 계약과 릴리스 안내 보존 검사를 통과해야 합니다.

## 검증

- 모바일: `npm run typecheck`, `npm test`, `npm run build`
- 데스크톱: `npm run typecheck`에 서버 계약·배포 가드 검사가 포함됩니다.
- 배포 전 원격 비교: `npm run deploy:apps-script -- -PreflightOnly`
- 실제 로그인은 화면에서 직접 입력하며 비밀번호·토큰·전체 API 응답을 로그로 남기지 않습니다. 서비스 버전, contractVersion, 출처 상태/건수, 조회 소요시간과 금지 필드 부재만 확인합니다.
