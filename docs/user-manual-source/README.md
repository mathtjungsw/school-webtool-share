# 사용자 설명서 제작 자료

웅천고 업무도우미 v1.1.2 사용자 설명서를 다시 만들 때 사용하는 제작 스크립트와 배포 안전 화면입니다.

## 개인정보 처리 기준

- 최종 PDF에서는 학생 이름과 학번만 흐림 처리합니다.
- 교사 이름, 부서, 교과, 담임과 위원회 명단은 사용 흐름 확인을 위해 그대로 표시합니다.
- 학생 정보가 보이는 원본 캡처는 로컬 제작 폴더에만 보관하며 공개 저장소에는 올리지 않습니다.
- `screenshots-safe`에는 학생 이름·학번을 가린 최종 화면만 보관합니다.

## 파일 구성

- `build_user_manual_expanded.py`: 82쪽 상세 설명서 생성
- `build_user_manual.py`: 공통 문서 구성, 메뉴 설명과 PDF 스타일
- `make_install_guide_images.py`: v1.1.2 설치 안내 화면 생성
- `screenshots-safe`: 메뉴와 단계별 배포 안전 캡처

## 다시 만드는 순서

1. 프로그램 화면이 바뀌면 같은 번호와 메뉴명이 포함된 파일명으로 캡처를 교체하고, 학생 이름·학번만 가립니다.
2. `make_install_guide_images.py`를 실행해 설치 안내 화면을 갱신합니다.
3. `build_user_manual_expanded.py`를 실행합니다.
4. `docs/웅천고_업무도우미_사용자설명서_v1.1.2.pdf`를 전 페이지 렌더링하여 잘림과 개인정보 노출 여부를 확인합니다.

설명서 버전이 바뀌면 두 제작 스크립트의 프로그램 버전, 설명서 제작 버전, 출력 파일명을 함께 변경합니다.
