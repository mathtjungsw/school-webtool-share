# 웅천고 업무도우미 사용자 설명서

- 프로그램 버전: v1.1.2
- 설명서 제작 버전: v1.1.2-r1
- 제작일: 2026-08-10
- 파일: `웅천고_업무도우미_사용자설명서_v1.1.2.pdf`

PDF는 총 82쪽이며, 첫 설치부터 전체 메뉴의 실제 화면·상세 사용법·결과 확인·문제 해결 순서를 초보자 눈높이로 설명합니다.
간결 설명에는 상세 설명으로 이동하는 내부 링크가 있습니다.
업무센터, 교환·대강 계획, 학생별 시간표, 출석부 출력에만 중요 표시(★)를 붙이고 탭·미리보기·자동 반영까지 별도 상세 설명을 제공합니다.
Windows 보호 화면과 설치 마법사도 단계별 그림으로 안내합니다.
화면 예시에서는 학생 이름과 학번만 흐림 처리하며 교사 이름은 그대로 표시합니다.
향후 설명서 개정을 위해 제작 스크립트와 학생 정보가 가려진 화면 캡처를 `user-manual-source`에 보관합니다. 원본 캡처는 공개 저장소에 포함하지 않습니다.
